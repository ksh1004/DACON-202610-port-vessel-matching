# 명시적 제원 관계·모음 보존 철자 입력 실험

2026-10-30. **입력 진단·BGE4개 모델 학습·저장 모델 검사를 완료했으나 두 형식 모두 기각했다.** 같은fold1·4의v12 testlike **0.9087787707**에대해두형식모두 **0.9072124341**이었다. 실제 최고는v12 Public **0.9065951735**, 서버9분51초, 실제제출9회다. 호출부호·동일선박조회 제외 방침을 유지한다. [전체 결산](../experiments/representation_iteration_20261030.json)

## 1. 먼저 기각한 가설: 입력이 잘리는가

질의·후보의 실제 토큰을 검사했다. fold1·4에서seed42 학습 그룹의앞256개씩과 기존 신경망이활성화된검증그룹을사용했으며오답여부로고르지않았다. Qwen과BGE 각각 **15,756쌍**을확인했다.

| 검사 | Qwen | BGE |
|---|---:|---:|
| 검사한 쌍 | 15,756 | 15,756 |
| 최대 전체 입력 길이 | 244 | 237 |
| 기존256토큰에서 잘리는 쌍 | **0** | **0** |

Qwen의접두/접미지시까지포함한길이를확인했고후보이름·톤수·선종·국적의잘림도없었다. 따라서 이번에는입력길이를늘려누락정보를복원한다는가설로진행하지않았다. 신경망이실행되지않는모든행까지의전수검사나실제test의조사는아니다. [입력 진단](../experiments/token_budget_20261030.json), [도구](../tools/audit_token_budget.py)

## 2. 새로 비교하는 입력 표현

기존모델도원문한글과영문을받으므로모음정보가완전히사라져있던것은아니다. 이번가설은 **같은관측정보를모델이비교하기쉬운형태로표현하면선택이좋아지는가**다. 다음두구성을 새성능확인전에 고정했다.

- `compact`: 짧은필드명으로이름·자음키·GT/IGT·선종·국적·최대4개음역을표현하고, 후보GT와질의GT/IGT의관계를문서에명시한다.
- `characters`: 위형식에모음을보존하는한글규칙로마자철자열과영문문자열을문자별로띄운보조표현을추가한다. 후보우선순위는characters→compact다.

톤수관계는같음·1%이내·5%이내·20%이내·다름·알수없음으로고정했다. 수치는현재질의와후보에서만계산한다. 양수가아니거나결측이면unknown이며정수/실수표현은정규화하고비정수값은float의repr을보존한다. 원시관측톤수도같이표현하므로관계구간만남기는모델은아니다.

철자열은기존`learned_alignment.observed`의고정초성·중성·종성표만사용한다. 관용후미호등의기존이름정리규칙은보조철자열에적용하며, 정규화한원문도별도로남긴다. 학습된37×37정렬행렬·외부사전·이름별예외·호출부호표는로드하지않는다.

[Ditto](https://arxiv.org/abs/2004.00584)는입력의중요부분을강조하는개체매칭연구이고, [FiT5](https://arxiv.org/abs/2305.14685)는다양한순위근거를템플릿입력으로통합하는연구다. 이구현은두논문의전체모델·손실·벤치마크를재현하지않으며, 두연구가본대회의개선을보장하지않는다. 후보간공동attention도추가하지않는다.

## 3. 통제한 자료와 학습

직전[8/20후보학습](listwise_training_20261030.md)의 **8후보대조군**을읽기전용으로재사용한다. 같은1,200개질의·정답/음성후보·시드42·공개원본BGE·LoRA8·학습률1e−4·microbatch1/누적2·600업데이트를사용하며 입력토큰만바꾼다. 대조군성능을이미알고있는상태의새실험이며새로운사전미관찰대조군이라고부르지않는다.

| 자료 | fold1 | fold4 |
|---|---:|---:|
| 학습그룹 | 1,200 | 1,200 |
| 그룹당후보 | 8 | 8 |
| 학습선박 | 286 | 289 |
| 학습/검증선박중복 | 0 | 0 |
| 같은대조군1,200그룹의중앙/최대토큰 | 187 / 237 | 187 / 237 |
| compact 중앙/최대토큰 | 116 / 174 | 116 / 174 |
| characters 중앙/최대토큰 | 150 / 228 | 150 / 228 |

같은질의와업데이트수의비교이며토큰계산량까지같은실험은아니다. compact는직렬화와수치관계표현을함께바꾸므로그개별효과를분리하는대조군은아니다. characters와compact의차이는추가철자표현이다.

입력은조용히자르지않고384토큰상한을넘으면오류를낸다. 학습자료는두형식모두상한미만이다. 후보순서를뒤집었을때토큰순서도정확히뒤집히며, ID·호출부호변경은입력에영향이없음을확인했다.

기존학습루틴을새전용폴더·프로토콜로호출하고기존코드·모델·실험자료를덮어쓰지않는다. 공통루틴의로그접두사`list20`은재사용된학습기표시이며, 별도`EXPLICIT mode=...`행과새실험지문·전용폴더로현재구성을구분한다.

## 4. 결과 확인 전에 고정한 판단 기준

[사전 프로토콜](../experiments/encoder_explicit_v1_protocol.json)은새입력모델의학습·정확도측정전에저장했다. 목표Public0.97을유지하면서작지만일관된개선을검증하도록이번초기조건을별도로정했다. 결과를본뒤기준을낮춘것이아니다.

| 단계 | 조건 |
|---|---|
| 초기fold1·4 | v12대비testlike+0.001이상, 두fold모두비하락, 원본정답손실0, hard/단어생략한글−0.001이상, 대조군대비+0.001, 선박bootstrap95%하단>0 |
| 별도fold3 | seed2026103002의고정변형·학습전용검색·few-shot선박제외, 평균하락−0.002이내 |
| 전체5-fold | testlike+0.002이상,4개이상fold개선, 원본OOF비하락, hard/단어생략한글−0.001이상, 대조군대비+0.001, 선박bootstrap95%하단>0 |

반복사용한합성CV이며CI는탐색적진단이지선택편향까지보정한통계보장이아니다. 기존v8후보검색매퍼의역사적예외도남아있다. 최종모델·새ZIP은전체조건과실제행독립/시간검사를통과한뒤에만진행하며실제업로드는하지않는다. BGE12.5%를교체하는이비교만으로0.97달성경로를확보했다고주장하지않는다.

## 5. 실제 학습·초기 결과

fold1·4×두형식의4개모델이각600업데이트·합계2,400업데이트를완료했다. 모두손실/기울기가유한했고초기학습파라미터SHA256은기존대조군과같았다. 같은기존20후보에서v8 75%+기존Qwen12.5%+새BGE12.5%로비교했으며기존신경망생략행은유지했다. 평가에정답후보를주입하지않았다.

| 같은fold1·4 | testlike | v12대비 | 대조군대비 | 변형회복/손실 |
|---|---:|---:|---:|---:|
| v12 | **0.9087787707** | 기준 | — | — |
| 기존1,200그룹JSON대조군 | 0.9070876816 | −0.0016910891 | 기준 | — |
| characters | 0.9072124341 | −0.0015663366 | +0.0001247525 | 10 / 17 |
| compact | 0.9072124341 | −0.0015663366 | +0.0001247525 | 11 / 18 |

characters의fold별차이는+0.0007061404/−0.0034368231, compact는−0.0007061404/−0.0022743682다. characters의bootstrap95%는[−0.007227,+0.003135], compact는[−0.007607,+0.003432]로두구간모두0을포함했다. 원본정답과단어생략한글정확도는유지했으나GT결측0.970297→0.962376, 생략+결측0.566337→0.560396으로하락했다.

hard는characters1행회복/2행손실, compact3행회복/5행손실이었다. 대조군대비아주작은차이와한fold의상승만으로채택하지않고두후보모두선택null을잠갔다. 전체점수가같아도사례와fold변화는달랐으며사후fold별선택을하지않았다. [최종 초기 비교](../experiments/encoder_explicit_v1_audit.json), [선택](../experiments/encoder_explicit_v1_selection.json)

최종선택에는공통집계기의검사와사전고정한bootstrap하단>0검사를함께썼다. 공통집계기원본은`encoder_explicit_v1_base_audit.json`, 추가조건을포함한최종기록은위`audit.json`과`screen_locked.json`이다.

## 6. 실행 검사와 보존

네저장모델을다시읽어고유질의6개×두형식12개모델·질의조합에서저장점수·최종v12결합예측·행역순/부분집합/단독·후보역순일치를확인했다. ID·호출부호변경은토큰에영향이없었다. [실행 검사](../experiments/encoder_explicit_v1_runtime_checks.json)

8개체크포인트슬롯을CPU로읽어옵티마이저상태의유한값과난수상태를확인했다. 이는GPU중단·재개후전체재학습을재현한검사는아니다. 이번모델검사는새ZIP전체실행도아니다.

등록입력·소스50개, 기존v12 소스13개·ZIP전체SHA256·과거연구스냅샷을확인했다. 주실행·별도실행검사·최종결산프로세스는모두반환코드0이었다. [입력 실험 결산](../experiments/explicit_input_iteration_20261030.json)

실패후입력길이·철자표현·숫자구간·혼합비율·계수를다시탐색하지않았다. 별도fold3·전체5-fold·제출용전체학습·새ZIP·실제제출은없다. 입력이짧아졌다는사실과정확도가올랐다는사실은구분하며, 이번구성에서모음보조표현의전체개선근거도얻지못했다.

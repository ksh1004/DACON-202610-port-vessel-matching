# 모호한 음성 후보의 학습 압력 완화 실험

2026-10-29. 상태: **두fold 세 조건의 모델6개 학습·평가 완료, 초기 조건 미달로 기각**. 모호성 완화는 원래 손실 재학습보다+0.000125였지만 v12보다-0.001040이었다. 새 최종 모델·ZIP·실제 제출 없이 v12를 유지한다. 실제 최고는v12 Public0.9065951735·591초·제출9회이며 목표0.97은 미달이다. [선택 결과](../experiments/encoder_ambiguity_v1_selection.json), [전체 결산](../experiments/encoder_ambiguity_v1_final.json)

## 가설과 고정 조건

[관측 모호성 진단](observation_aware_redesign_20261029.md)에서 일부 학습 음성이 정답과 같은 관측 이름 구간·제원을 공유했다. 이 후보를 강하게 밀어내는 학습 압력을 줄였을 때 일반화가 좋아지는지 단독 비교한다. 다른 선박을 같은 개체로 재라벨링하지 않는다.

실험 전에 [프로토콜](../experiments/encoder_ambiguity_v1_protocol.json)을 등록했다. 소스·공식입력·fold·기존 음역 캐시·strict 음성 채굴기 해시를 고정했고, 새 신경망 학습과 새 점수 측정 전에 조건을 잠갔다.

- 외부screen은fold1·4다. 과거 실험에서 등장한 선박이며 완전히 미관찰 검증은 아니다.
- 공개BGE-reranker-v2-m3에서 세 조건을 각각 새로 학습한다. 원래v12의2,400그룹·후보8개·입력256토큰·LoRA8/alpha16/dropout0.05·학습률1e-4·1epoch·batch2·seed42를 유지한다.
- 세 조건은 원래 손실(`none`), 모호한 음성 완화(`targeted`), 같은 수의 임의 음성 완화(`random`)다. **채택 가능한 후보는targeted 하나**이며 대조군을 사후 대안으로 선택하지 않는다.
- 완화 대상 음성의 가중치는0.25로 하나만 고정한다. 양성과 나머지 음성은1이다. `CE(scores+log(weights), positive0)`로 계산하며 정답 인덱스와 후보·입력을 바꾸지 않는다.
- targeted는 실제 한글 질의에서 기존 질의별 음역 빔의 같은 영문 문자열이 두 후보의 연속 단어 구간에 존재하고, 질의에 있는 국적/선종에 대해 후보 값이 같으며, GT/IGT 중 양수가 있으면 후보GT도 같은 음성을 고른다.
- random은 같은 질의의7음성 중 동일 개수를 균등 비복원 추출한다. 시드는`20261029+10000*fold+groupPosition`이며 실제 완화 대상과 겹칠 수 있다. 이 난수는 학습 표본 추출에만 쓰며 추론 특징이 아니다.
- 각 조건에서 모델 생성 직전에seed42를 재설정한다. 초기 학습 파라미터 해시·학습 토큰 해시·배치 순서·업데이트 수를 비교한다.
- 평가 결합은 기존v12와 같은v8 75%+기존Qwen12.5%+새BGE12.5%다. 총신경망25%가 유지되므로 기존 승자 보존 생략 경계1/3도 유지한다. 이 실험은손실 가설의 작은 비교이며 그 구조만으로Public0.97에 닿는다고 주장하지 않는다.

음성을 모두 완화하는 그룹에서는 두 방법이 겹칠 수밖에 있다. 임의 대조군에서 실제 대상을 제외하는 사후 변경은 하지 않는다. 질의별 완화 개수는 두 조건에서 모두 같고, 양성을 완화하는 경우는0이다.

원래 손실과 가중치1인 새 구현의 손실·기울기가 비트 단위로 같음을 검사했다. 가중치0.25의 수동 가중합 식도 일치했다. ID·호출부호 변경 후 실제 토큰과targeted 판별이 같았으며, 양성을 제외한 후보 순서를 바꾸어도targeted 마스크가 같은 후보를 가리켰다. [검사 결과](../experiments/encoder_ambiguity_v1_setup_checks.json)

## 재학습 대조군과 기존 모델의 차이

fold1의 세 조건은 실제 초기 학습 파라미터 해시와 토큰 해시가 같고 각각1,200업데이트를 유한한 손실로 마쳤다. 다만 새로 재학습한 원래 손실 조건은 과거v12 가중치·예측의 정확한 재생은 아니다. 총1,368행 중15행에서 v12 결합의 선택이 달랐고, 실제 한글 활성249행의 BGE 점수도 비트 단위로 일치하지 않았다. 최대 로짓 차이는5.984375였다. 이를 단순한 작은 BF16 로그 차이로 처리하지 않는다. [재생 진단](../experiments/encoder_ambiguity_v1_replay_checks.json)

과거와 현재의 학습 캐시 이름·설정은 같았다. 현재 저장한 토크나이저JSON의 차이는 기본truncation 상태뿐이었고, 실제로 저장한 토크나이저로fold1의 전체27,360평가 쌍을 다시 인코딩했을 때 캐시 토큰과 정확히 같았다. 따라서 이 점검에서는 토큰화 차이를 찾지 못했다. [토큰 검사](../experiments/encoder_ambiguity_v1_tokenizer_checks.json)

학습 재생 차이의 정확한 원인은 아직 확정하지 못했다. 같은 시드가 과거 모델의 비트 단위 재학습을 보장한다고 주장하지 않는다. 새 세 조건의 초기화와 입력을 맞춘 대조군 비교를 사용하되, 실제v12 대비 조건도 동시에 요구한다. 재학습 대조군보다 나아진 것을 기존 최고 성능 개선으로 바꿔 보고하지 않는다. 이 차이와 결과의 탐색적 한계는 최종 결산에도 남긴다.

fold4의 재학습 대조군도 기존 선택을1,662행 중1,651행에서 보존했고, 한글 활성334행의 최대 로짓 차이는5.3046875였다. 두fold 전체3,030행 중26행의 선택이 달랐다. 이는 기존모델 재생의 한계이며 모호성 완화로 회복한 행 수로 세지 않는다. [두fold 재생 비교](../experiments/encoder_ambiguity_v1_final.json)

## 실제 초기 평가 결과

아래는 **동일한fold1·4 합산 testlike**다. 전체5-fold v12의0.9118708558이나 실제 Public0.9065951735와 비교하는 표가 아니다.

| 조건 | testlike | 기존v12 대비 |
|---|---:|---:|
| 기존v12 | **0.9087787707** | 기준 |
| 원래 손실 재학습 | 0.9076144143 | -0.0011643564 |
| 모호한 음성 가중치0.25 | 0.9077391668 | -0.0010396040 |

모호성 완화는 원래 손실 대조군 대비+0.0001247525, 임의 완화 대비+0.0014277228이었다. 원래 손실 대조군 대비 개선은 최소+0.001에 미달하고, 기존v12와의 차이는 최소 개선+0.003과 반대 방향이었다. 임의 완화보다 나았다는 사실만으로 성능 개선을 주장하지 않는다. [합산 비교](../experiments/encoder_ambiguity_v1_screen.json)

fold1은v12 대비+0.001043860, fold4는-0.002754513으로 최악fold 하락 제한에도 미달했다. 선박별bootstrap95% 구간은[-0.005861489,+0.002304456]이다. testlike 변형6행 회복·11행 손실, hard0행 회복·2행 손실, clean 변화0행이었다. 단어 생략 한글은0.819802로 유지됐지만 GT결측은0.970297→0.962376, 생략+결측은0.566337→0.564356으로 하락했다. [후보 상세](../experiments/encoder_ambiguity_v1_targeted_audit.json)

few-shot 선박을 제외해도v12의0.9095147281에서0.9084411085로 하락했다. 재학습 대조군과 기존v12의 차이보다도 작은 순증이므로, 이번 단일 설정에서 손실 보정의 실질적인 성능 개선 근거를 얻지 못했다. 이것을 모호성 인식 학습 전체의 무효라는 결론으로 확대하지 않는다.

세 조건×두fold의 초기 파라미터·학습 토큰 해시는 실제로 같았고, 총7,200업데이트에서 손실이 유한했다. 초기 조건을 통과하지 못해fold3 별도 진단·나머지fold·전체5-fold·최종 전체 학습·패키지 단계로 확대하지 않았다. ByT5와 조건부 사전확률도 자동 실행하지 않았다.

저장한6개 모델에서 실제 한글 질의18개를 다시 실행해 캐시 점수와 완전히 일치함을 확인했다. 질의 역순·부분집합/단독 실행·질의 안의 후보 순서 변경·ID/호출부호 변경에서도 점수가 같았다. 이는 실제 저장 판별기의 검사이며 새 제출ZIP 전체 실행 검사는 아니다. [실제 실행 검사](../experiments/encoder_ambiguity_v1_runtime_checks.json)

200업데이트의 실제 체크포인트에서 학습 텐서148개 항목과 어댑터의 정확한 복원·옵티마이저 유한 상태·난수 상태를 CPU에서 확인했다. 전체 GPU학습의 완전 재현 검사는 아니다. [체크포인트 검사](../experiments/encoder_ambiguity_v1_checkpoint_checks.json)

등록한 소스·입력30개 파일의 해시와 기존v12 소스13개, 기존6,975,754,790바이트 ZIP의 전체SHA256을 확인했다. 검증용6개 모델과 준비/예측 자료는 보존한다. 배포 후보가 아니므로 새 ZIP을 생성하거나 제출하지 않았다.

## 확대 기준

초기 두fold에서 v12 대비testlike+0.003 이상, 최악fold-0.002 이상, hard 한글과 단어 생략 한글-0.002 이상, clean 기존 정답 손실1행 이하를 모두 요구한다. 원래 손실과 임의 완화 각각보다testlike+0.001 이상도 필요하다. 초기 파라미터와 학습 토큰이 실제로 같아야 한다.

통과 시fold3에서별도의 고정7종 진단을 한다. seed2026102901에기록sample_id 해시를 더한 난수로 단어 생략·GT±15% 등을 고정하고,60%앞부분 약칭도 포함한다. 검색·범주 매퍼는 학습선박만으로 적합하고few-shot 선박은 제외한다. 평균 정확도 하락 한도는-0.002다. 동일 선박의 과거 진단이 있으므로 완전 신규 검증으로 부르지 않는다.

진단 통과 후 나머지fold와 대조군을 완료한다. 전체5-fold testlike+0.005·4개fold 개선, hard한글-0.001/단어생략-0.002/OOF-0.0006 이상 및 두 대조군 각각보다+0.001 이상을 요구한다. 최종 전체 학습·패키지는 그 이후다. 어느 단계든탈락하면 이 실험에서 계수·대상 기준을 다시 탐색하거나ByT5/사전확률 학습을 자동 시작하지 않는다.

## 실행과 현재 범위

```powershell
.venv/Scripts/python.exe -m tools.register_ambiguity_iteration
.venv/Scripts/python.exe -m tools.check_ambiguity_setup
.venv/Scripts/python.exe -m tools.run_ambiguity_iteration
```

학습200업데이트마다어댑터·옵티마이저·난수 상태를 저장한다. 병합한 가중치는BF16 저장·재로딩 후 실제 평가한다. 학습 재개와 이미 끝난조건은저장된 프로토콜 지문을 확인한다. 완료한선택 파일이 있으면선택 도구는재탐색을 거부한다.

현재 선택은`null`로 기록되어 있다. 이미 완료한 실험의 가중치나 조건을 바꾸어 재실행하지 않는다. 사후 검사와 결산은 다음 명령으로 수행했다.

```powershell
.venv/Scripts/python.exe -m tools.check_ambiguity_runtime --checkpoint
.venv/Scripts/python.exe -m tools.check_ambiguity_runtime
.venv/Scripts/python.exe -m tools.finalize_ambiguity_iteration
```

로그는`experiments/run_ambiguity_iteration.log`, 각fold 로그는`experiments/encoder_ambiguity_v1_screen_fold1_run.log`와`...fold4_run.log`다. 기존v12 소스·가중치·ZIP·실제 결과는 보존하며 호출부호·동일선박 조회·외부선박 자료·test 분포를 사용하지 않는다.

# 기존 Kanana의 한글→영문 후보 구간 확률 진단

2026-10-29. **48척 진단에서 v12의17개 정답이15개로 하락해 확대하지 않았다.** 회복0척·손실2척으로 최소순증3척 조건에 미달했다. 실제 Public 점수나 전체CV 정확도가 아니다. [진단 결과](../experiments/forward_kanana_v1_probe.json), [학습 이름 모델과 함께한 결산](../experiments/name_iteration_20261029.json)

## 새로 시험한 것

[ByT5 두 설정](byte_names_20261029.md)이 초기 조건에 미달한 뒤, 별도 가설로 이미 있는 공개범용Kanana-1.5-2.1B의전방확률을시험했다. 새 가중치나새학습자료는받지않았고 모델을학습하지않았다.

기존생성영문4개와후보의문자유사도를비교하는대신, 공식후보의영문구간을직접이어읽어`P(영문구간+assistant 종료 | 관측한글명)`을계산한다. 이전고정역방향`P(한글명|영문명)`이나4B의후보번호공동선택과구분한다.

기존음역지시와12개고정예시에대문자출력·관측하지않은단어추가금지를명시했다. 예시영문명도대문자정규화했다. 실제chat template의assistant 종료토큰128009를확인해사용했으며일반텍스트EOS와혼동하지않는다. 프롬프트·계수·점수형태를보고서결과에맞춰수정하지않았다.

## 고정한 진단

fold0·2의실제한글약칭/약칭+결측중기존v12 앵커가새30%신호로바뀔수있는영역을사용한다. 정답은원래상위20안에있는경우만진단대상으로삼되후보에정답을추가하지않는다. 고정few-shot 선박을제외하고seed20261029로후보사례를섞어선박당하나씩48척을뽑았다. 기존예측의정오여부로사례를고르지않았다.

모든후보의서로다른연속영문구간을만들고전체이름0.5/나머지구간합0.5의고정사전확률로가중합한다. v12 70%+새이름확률30%를유지한다. 원래프로토콜의초기조건을느슨하게바꾸는대안이아니라, 별도로등록한작은사전진단이다. [등록조건](../experiments/forward_kanana_v1_probe_protocol.json)

FP32확률계산을포함하는BF16모델·SDPA·고정batch32/pad512/logits33으로2,395쌍을150.7초에계산했다. 잘림이없고역순·단독/동반쌍변경의점수가완전히같았다. 원래v12는17/48, 새결합은15/48로순증-2였다. 48척의선정된어려운사례비율을대회점수로환산하지않는다.

프로토타입은기존역방향배치구현을재사용했다. 부모클래스가돌려주는메타데이터일부에역방향설명/프롬프트체크섬이남아있어, 종합기록에실제전방프롬프트의SHA·입력필드·대상+종료점수정의를별도로정리했다. 원시기록을보존했으며토큰·점수·선정사례·판단은바꾸지않았다.

새전체fold평가·최종모델·ZIP·실제제출은없다. 호출부호·동일선박조회·외부선박자료·test분포는사용하지않는다. 기존v12 Public0.9065951735·591초·제출9회를유지한다.

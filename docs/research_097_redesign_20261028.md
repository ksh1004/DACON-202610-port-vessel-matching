# 0.97 목표: 최신 연구와 결정 구조 재설계

조사일 2026-10-28. 실제 최고는 **v12 Public 0.9065951735 / 서버 591초**다. 사용자는 최근 실패한 실험을 반복하지 않고 논문·최신 자료를 조사해 0.97에 도달할 개선안을 요청했다. 아래는 **새 진단 결과와 후속 구현 제안**이며 새 제출 모델의 성능 보고가 아니다.

**권고:** 후보 영문명에서 관측 한글명이 나올 확률을 새 이름 증거로 만들고, 이름·제원의 신뢰도에 따라 최종 후보를 선택하도록 재순위기를 바꾼다. 후보들을 함께 읽는 listwise 모델과 큰 교사의 증류를 경쟁안으로 검증한다. BGE 12.5% 부분만 교체하는 경로는 목표까지 확장하기 어렵다.

## 1. 이번에 새로 확인한 구조적 제약

`tools/audit_v12_structural_limits.py`로 저장된 5-fold 후보·기본 점수·Qwen 점수를 다시 읽어 계산했다. v12 0.9118708558, v8 0.9049590170을 재현했고, 두 신경망의 후보 순서 일치와 오라클의 단조성을 검사했다. [재현 결과](../experiments/v12_structural_limits.json)

| 정답을 아는 가상 선택기의 조건 | 로컬 testlike |
|---|---:|
| 실제 v12 | 0.911871 |
| 기존 후보·분기·v8 75%·Qwen 12.5% 고정, BGE 12.5%만 완벽하게 교체 | **0.947200** |
| 두 신경망의 합계25%를 완벽한 분포로 교체 | **0.973554** |
| 신경망40%를 완벽하게 교체하고 생략 경계도 그 비율에 맞게 변경 | 0.986949 |
| 현재 상위20 내에서 자유롭게 정답 선택, 실제 비한글 경로 유지 | 0.988806 |

**위 값은 정답을 이용한 낙관적 진단이고 실제 성능이나 Public 상한이 아니다.** 각 행에서 정답 후보에 확률1을 줄 수 있다고 가정했다. 같은 관측 입력에 서로 다른 정답을 가진 행까지 일관되게 해결하는 학습 가능한 모델을 구성한 것도 아니다.

현재 결합은 `0.75 × 기존 점수 + 0.125 × Qwen + 0.125 × BGE`다. BGE만 바꿀 때 정답의 새 점수 기여는 최대0.125이므로 기존 우승 후보와의 차이가 크면 뒤집을 수 없다. 최근 A1/A2/B가 모두 이 제약 안에서 평가됐다. **그 구성으로 0.97을 목표로 한 새 학습만 반복하는 것은 우선순위가 낮다.**

두 신경망을 모두 바꿔도 합계25%를 고정하면 로컬 0.97은 현재부터 이론적으로 회복 가능한 오차의 **94.24%**를 해결해야 한다. 상위20에 정답이 있는데도 25% 점수로 역전할 수 없는 행이121개이며, 그중34개는 신경망을 실제 실행한 행이다. 계산 생략만 해제해도 해결되지 않는다.

이미 신경망 비중40%를 실제 시험해 실패했다. 위40% 오라클은 **단순 비중 확대를 추천하는 근거가 아니라**, 새 판별 근거와 더 유연한 최종 결정을 함께 개발해야 한다는 근거다. 기존 모델의 1등 예측 중 정답을 골라주는 이전 오라클0.930755도 현재 1등 예측의 상호보완성이 제한적임을 보여준다. 다만 그것이 모든 점수 결합의 수학적 상한은 아니다.

이름·GT·IGT·선종·국적·입항연도의 완전히 같은 관측값에 여러 정답이 연결된 경우도 점검했다. 로컬 평가의37개 입력에서 충돌하며 그 손실만 반영한 경험적 상한은0.995439다. **완전히 같은 입력의 충돌만으로 0.97이 막힌다는 근거는 없다.** 반대로 이것이 다른 모호성·정보 부족이 없거나0.97이 실현 가능함을 보장하지도 않는다.

## 2. 0.97이 요구하는 실제 개선 규모

현재 Public에서 목표까지 **+0.0634048265**, 남은 가중 오차의 **67.88% 회복**이 필요하다. 공식 지표는 한글0.7/비한글0.3이다. 비한글 성능이 로컬0.998187과 같다고 *가정*하면 한글 정확도는 현재 Public에서 역산한0.86734에서 **0.95792**까지 올라야 한다. 실제 test의 언어별 정확도·행 수는 공개되지 않았으므로 이 역산은 가정이다. [공식 평가](https://dacon.io/competitions/official/236771/overview/evaluation)

현재 로컬 오차의64.1%가 약칭+결측,32.5%가 약칭이다. 현재 인공 혼합비를 그대로 놓고 원본·톤수 결측 성능을 유지하면, **약칭 정확도95%와 약칭+결측86%**를 달성할 때 로컬값은0.970365다. 현재 각각82.20%와57.51%이므로 작은 개선이 아니다. 이 숫자는 목표를 구체화한 산술 예시이며 Public 예측이나 방법의 예상 효과가 아니다.

## 3. 제안 A — 후보 조건부 음역 점수

### 바꾸는 점

현재는 한글 질의에서 영문4개를 생성하고 후보 이름과 비교한다. 새로운 방법은 **각 후보의 영문 이름이 주어졌을 때 관측 한글 이름이 나올 가능성**을 직접 계산한다.

예를 들어 `루니`를 관측했으면 `Luni`와 `SS Luna` 각각에 대해 한글 관측의 토큰 로그확률을 계산한다. 영문4개 중 어떤 철자가 생성됐는지에만 의존하지 않고, 실제 관측의 모음·음절 전체를 설명하게 하는 가설이다. 이전의 Kanana 후보 번호 직접 생성, 카탈로그 한글 이름 합성 후 BGE 사전 학습, 37×37 문자 비용과는 다른 점수다.

근거인 **UPR, EMNLP 2022**는 문서가 주어졌을 때 입력 질의의 생성 확률로 문서를 재순위한다. 그 연구의 질의/문서를 여기서는 관측 한글명/후보 영문명으로 바꾸는 것이며, 선박 음역에 효과가 있다는 실험은 아직 없다. [논문](https://aclanthology.org/2022.emnlp-main.249/)

### 첫 구현

- 이미 로컬에 있는 공개 Kanana를 사용한다. 후보 영문명과 음역 지시만 입력하고, 실제 한글명을 강제로 이어 읽어 **관측 토큰의 로그확률만** 합산한다. 선박의 실제 제원이나 외부 사실을 생성하지 않는다.
- 전체 이름의 점수부터 측정한다. 약칭 처리는 후보의 단어 생략 가능성을 명시한 별도 변형으로 비교한다. 생략된 단어 조합을 여러 개 점수화한다면 학습 fold에서 정한 생략 확률로 가중 합해 긴 이름이 공짜로 유리해지지 않게 한다.
- 이름 점수는 이름 호환성만 담당하고, GT·IGT·선종·국적은 기존 수치 특징과 별도 판별 경로에서 사용한다. 관측에 없는 접미사를 모델에게 복원하라고 강제하지 않는다.
- 같은 질의에 대해 후보와 무관한 `log P(한글명)`을 빼는 PMI 항은 후보 순위를 바꾸지 않는다. 이를 새로운 재순위 개선으로 세지 않는다.
- 기존 상위20의 전체 행을 대상으로 측정한다. 기존25% 결합을 가정한 계산 생략이 새 방법의 성능 진단을 가리지 않도록 한다. v12와 비교할 후보 집합은 동일하게 둔다.

처음 확인할 것은 전체 이름에서의 구별력, 약칭에서의 회복/손실, 기존 모델과 다른 오답인지, 후보 수에 따른 실제 시간이다. 이름만으로 동명·자매선의 정답을 확정할 수 있다고 가정하지 않는다.

## 4. 제안 B — 후보를 함께 비교하는 최종 선택기

### 핵심은 공동 입력과 최종 결정권

현재 학습도8개 후보에 대한 cross-entropy를 사용한다. 따라서 단순히 listwise loss로 이름을 바꾸는 것은 새 방법이 아니다. **현재 신경망이 후보 쌍을 따로 인코딩한다는 점을 바꿔**, 질의와 후보20개가 서로의 이름·제원 차이를 볼 수 있게 한다.

`GT는 같지만 이름이 다름`, `이름은 비슷하지만 GT가 다름`, `GT가 모두 결측이라 발음이 주요 근거`라는 관계를 학습한다. v8 점수도 하나의 증거로 넣을 수 있지만, v8 75%를 반드시 보존하는 구조는 강제하지 않는다. 한 test 행과 공식 카탈로그 후보만 공동으로 읽는다. 다른 test 행 간 매칭 제약이나 투표는 사용하지 않는다.

**Match, Compare, or Select?, COLING 2025**는 개체 매칭에서 독립 쌍 판정과 후보 비교·선택을 비교하고 선택 방식의 장점을 보고했다. 다만 논문의 여러 기록 간 전역 일관성 기법을 이 대회에 그대로 도입하지 않는다. [논문](https://aclanthology.org/2025.coling-main.8/)

### 최신 실행 후보: Jina Reranker v3.5

2026년7월20일 논문,8월3일 공개 발표를 확인했다. **0.6B** 모델이 질의와 후보 목록을 함께 읽고 점수화하며, 필드·구조화된 기록의 검색도 학습 대상으로 다룬다. 공개 모델 카드의 동일 프로토콜에서 Struct-IR는 v3의38.7에서v3.5의48.3으로 증가한다. 이는 해당 검색 벤치마크의 nDCG@10이며 이 대회의 정확도 향상치가 아니다. [논문](https://arxiv.org/abs/2607.18152), [공식 모델 카드](https://huggingface.co/jinaai/jina-reranker-v3.5)

파일 메타데이터 확인 결과는596,836,352개 BF16 매개변수, 원시 가중치 약1.19GB다. config에 transformers4.57.3이 기록돼 있고, custom code가 참조하는 Qwen3 클래스가 로컬4.57.6에 존재한다. **정적 호환성 점검이며 가중치 로딩·실행시간을 검증한 것은 아니다.** 고정 revision과 코드 해시를 [조사 메타데이터](../experiments/research_097_sources_20261028.json)에 저장했다.

가중치는 **CC-BY-NC-4.0**이므로 대회 사용 범위 확인이 필요한 후보로 분류한다. 대안은 기존 다국어 BGE 표현에 작은 후보 간 attention을 붙이는 직접 학습 구조나 Apache-2.0 Qwen 계열의 후보 선택 학습이다. Jina를 반드시 써야만 가능한 설계가 아니다.

**Set-Encoder, ECIR 2025**는 후보 간 attention을 입력 순서에 강건하게 구성한 근거다. 동시에 이 논문은 통상적인 검색에서 잘 학습한 독립 쌍 모델과 공동 모델이 비슷할 수 있음을 보고한다. 따라서 후보 공동 입력의 우월성을 전제로 하지 않고 독립 인코딩과 동일 조건으로 비교한다. [논문](https://arxiv.org/abs/2404.06912), [저자 배포 코드](https://github.com/webis-de/set-encoder)

### 최종 결합을 학습할 때의 검증 조건

결측 여부·톤수 충돌·이름 점수·후보 간 격차를 입력으로 작은 최종 재순위기를 학습한다. 기존 모델들의 학습된 점수를 넣는 경우 **외부 검증 선박을 제외한 내부 분할에서 얻은 예측**을 학습용으로 사용한다. 현재 저장된5-fold 점수를 단순히 다시5-fold로 나눠 쌓으면, 다른 fold 모델이 현재 외부 검증 선박을 이미 학습한 경로가 생긴다.

첫 구현의 계산 부담을 줄이려면 새 이름 점수와 원시 쌍 특징으로 직접 재순위기를 학습하고, 기존 미세조정 신경망 점수를 학습 입력에 넣는 방식은 내부 교차 예측이 준비된 뒤 비교한다. 기존 계산 생략 경계도 새 최종 점수에 맞게 재검증한다.

## 5. 제안 C — 더 강한 교사를 먼저 검증하고 작은 모델로 증류

같은0.6B/기존 BGE에 약한 합성 음역만 더 넣은 실험B는 실패했다. 다음에는 **교사가 실제로 새로운 오답을 고칠 수 있는지 먼저 측정**한다. 공개 Apache-2.0인 [Qwen3-Reranker-4B](https://huggingface.co/Qwen/Qwen3-Reranker-4B)를 독립 후보 점수 교사로, [Qwen3-4B](https://huggingface.co/Qwen/Qwen3-4B)를 후보 공동 선택의 비교안으로 둘 수 있다. 두 모델의 역할은 다르다.

Rank-DistiLLM, ECIR 2025는 큰 모델의 순위를 hard/deep negatives와 listwise 학습으로 작은 교차 인코더에 전달한다. 여기서는 논문의 외부 학습 데이터셋을 가져오지 않고 **공식 train·catalog와 학습 fold에서 만든 후보**에 대한 교사 점수만 사용한다. 정답 supervision을 유지하며 틀린 교사 출력에 무조건 맞추지 않는다. [논문](https://arxiv.org/abs/2405.07920)

4B reranker의 원시 BF16 가중치만 약8.04GB라 기존6.98GB 패키지에 단순 추가하지 않는다. 오프라인 교사로 사용하고, 개선이 있는 경우 작은 모델에 옮기는 전략이다. 교사의 순위 자체가 v12보다 약하면 증류로 확대하지 않는다.

긴 설명을 생성시키는 방식은 첫 선택에서 제외한다. **Rethinking Reasoning in Document Ranking**은 여러 재순위 실험에서 긴 추론이 보정·일반화와 비용을 악화시킬 수 있음을 보고했다. 이는 모든 추론 모델의 실패를 뜻하지 않지만, 짧은 이름 매칭에서 긴 reasoning을 먼저 추가할 근거는 약하다. [논문](https://arxiv.org/abs/2510.08985)

| 1. 새 이름 증거 | Kanana 후보 조건부 로그확률, 전체 이름과 약칭 처리를 구분해 측정 | 동일 상위20에서 기존 모델이 놓친 정답을 회복하는지, 원본·약칭 손실과 시간 확인 |
| 2. 최종 결정 변경 | 새 점수+원시 제원 특징의 직접 재순위기, 또는 내부 교차 예측 기반 조건부 결합 | 기존75% 제약을 벗어나도 전체 성능이 좋아지는지 |
| 3. 공동 후보 비교 | Jina v3.5 또는 BGE/Qwen 공동 선택 구조와 독립 쌍 모델 비교 | 공동 입력의 추가 효과와 후보 순서 민감도 확인 |
| 4. 교사 증류 | 4B 교사 자체 검증 → 통과 시 작은 학생에 전달 | 교사보다 학생이 실제로 나아졌다고 추정하지 않고 각각 평가 |
| 5. 최종 평가 | 전체5-fold, 새 고정 변형 진단, 실제 신경망 경로·행 독립·시간·ZIP 검사 | 실제 Public은 사용자가 제출해 확인 |

빠른 탐색은 기존 fold0·2에서 하고 학습/검증 선박을 분리한다. 재사용한 CV이므로 점수 개선만으로 확정하지 않는다. 후보를 고정한 뒤 아직 이번 후속 후보에 사용하지 않은 fold3의7종 변형과 전체5-fold를 본다. 이 fold3 역시 과거 CV에 포함된 선박이며 완전히 미관찰 데이터라고 부르지 않는다. 새 변형 시드는 결과를 보기 전에 고정한다.

새 방향의 1차 확대 기준으로 **초기 두 fold +0.003 이상**, 최종은 **v12 대비 +0.005 이상·최소4/5 fold 개선**, hard 한글 하락최대0.001·톤수 있는 약칭 하락최대0.002·원본 OOF 하락최대0.0006을 제안한다. 이는 미래 실험의 채택 기준이며 아직 학습 전 등록하거나 통과한 것이 아니다. 다음 도약의 중간 확인점은 전체 로컬0.92→0.94→0.97로 두되, 순차 개선이 가능하다고 약속하지 않는다.

한 가지 인공 노이즈 혼합비에만 맞추지 않고 원본·약칭·결측·톤수 충돌·한글 표기 오류별 성능과 혼합비 변화에 대한 민감도를 함께 제시한다. 실제 Public 분포를 점수 몇 개로 역추정해 확정하지 않는다.

## 7. 자원·규칙과 낮춘 우선순위

공식 서버는 L4 22.4GiB, 추론 전체30분, ZIP10GB다. 현재591초는 추가 계산을 검토할 여지는 주지만 새 모델의 실행시간을 보장하지 않는다. 실제 test 크기가 비공개이므로3,000행 로컬 시간으로 서버 시간을 선형 확정하지 않는다. [평가 환경](https://dacon.io/competitions/official/236771/overview/evaluation)

공식 train·catalog와 공개 범용 사전학습 가중치 범위를 유지한다. `call_sign`·동일 선박 조회는 사용자의 제외 방침을 유지한다. 공개 질문 페이지에서는 호출부호와 정적 합성 음역 사용에 대한 운영진 답변을 이번에도 확인하지 못했다. 외부 사실을 생성하거나 외부 선박 데이터를 붙이는 방법을 개선안에 넣지 않는다. [규칙](https://dacon.io/competitions/official/236771/overview/rules), [조회 관련 질문](https://dacon.io/competitions/official/236771/talkboard/418273), [합성 음역 관련 질문](https://dacon.io/competitions/official/236771/talkboard/418272)

다음은 우선순위를 낮춘다.

- BGE만 동일12.5% 경로에서 재학습하기: 새로 확인한 구조적 상한.
- 시드·그룹 수·전체 신경망 비중만 바꾸기: 이미 실패한 비교와 겹침.
- 현재 문자 정렬에 가중치만 다시 맞추기: 신규 구별 근거가 늘지 않음.
- 카탈로그 합성 음역 규모만 키우기: 이전 약한 음역의 품질 문제가 먼저 남음.
- 후보20→50만 확대하기: 이전 진단의 최대 회복 여지+0.006700으로 목표 간격 대부분을 설명하지 못함. 새 판별기가 강해진 뒤 선택적으로 검토.
- test 전체 그래프·일대일 할당·빈도 보정: 행 독립 조건에 맞지 않음.

이번 조사에서는 새 가중치를 다운로드하거나 모델을 학습하지 않았다. 새 작업은 구조적 상한·입력 충돌의 재현 분석, 공식 논문·모델 카드·규칙 확인, 코드/라이선스/용량의 정적 점검, 실행안 문서화다. 0.97 달성은 미검증이며, 현 단계에서 수치로 보장할 근거는 없다.

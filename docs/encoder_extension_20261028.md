# v12 후속 개선 실험 결과

> 최종 상태: 네 가지 비교안이 모두 사전 두 fold 조건에 미달해 기각했다. **v12 Public 0.9065951735 / 서버 9분 51초를 유지**하며 신규 ZIP·실제 제출은 없다. 아래 점수는 각 안과 동일 fold의 v12를 비교한 로컬 값이며 전체 5-fold·Public 결과가 아니다.

기준일 2026-10-28. 현재 확인된 최고 Public은 사용자 보고 v12 **0.9065951735**, 서버 **9분 51초**다. 목표 0.97, 호출부호·train/test 동일 선박 조회 제외 방침을 유지한다. 기존 코드·가중치·제출 ZIP을 보존하고 별도 경로에서 실험한다.

## 가설과 사전 조건

v12 BGE 인코더는 학습 fold의 원본·증강 중 무작위 2,400개 그룹, 1 epoch만 학습했다. 입력 형식·모델·음성 선별·학습률·배치·epoch·결합 비율을 그대로 두고 **모든 적격 학습 그룹**을 사용한다. 모델 입력은 기존 이름·발음 키·제원·질의별 음역뿐이며 정답 ID·호출부호는 넣지 않는다.

최종 결합은 v8 75% + 기존 Qwen 12.5% + 새 BGE 12.5%로 고정한다. 가중치 탐색이나 좋은 체크포인트 선택은 하지 않는다. BGE는 같은 공식 고정 리비전에서 새로 학습하고, 병합 → BF16 저장 → 재로딩 후 평가한다. 한글 입력의 상위 20개만 처리하고 승자 보존 경계도 유지한다.

학습 전에 [프로토콜](../experiments/encoder_extension_protocol.json)에 다음을 기록했다.

1. fold 1·2에서 v12 대비 testlike +0.001 이상, 각 fold -0.002 이상, hard 한글 -0.002 이상, 단어 생략 한글 -0.003 이상, 원본 정답 손실 1행 이하를 요구한다.
2. 통과하면 기존 평가에 쓰지 않은 fold 0의 별도 7개 변형에서 비교한다. 검색·범주 매퍼까지 학습 선박으로 분리하고 few-shot 선박은 제외한다. 평균 정확도 하락 한도는 -0.002다. 공식 지표는 아니다.
3. 전체 5-fold는 testlike +0.001 이상, hard 한글 -0.001 이상, OOF -0.0006 이상, 단어 생략 한글 -0.003 이상, 3/5 fold 이상 개선을 요구한다.

같은 검증 세트를 반복 사용하는 탐색이며 기존 v8 평가 후보 검색 매퍼 예외도 남는다. 사전 조건을 통과해도 Public 상승이나 0.97을 보장하지 않는다.

## 사전 등록한 대안

학습 확대가 어느 단계에서든 탈락하면 기존 v12 모델을 유지한 채 **v8 60% + Qwen 20% + BGE 20%**의 단일 고정 비율을 비교한다. [대안 프로토콜](../experiments/encoder_confidence_protocol.json)은 점수 계산 전에 저장했다. 가중치 격자 탐색은 하지 않으며, 학습 확대가 모든 조건을 통과하면 이 대안은 실행하지 않는다.

이유는 기존 신경망 총 비중 25%에서 기준 모델의 큰 점수 차이를 넘을 수 없는 구조적 제약이다. 기존 점수를 그대로 재결합하는 것만으로는 40% 평가가 완성되지 않는다. 승자 보존 경계가 1/3에서 2/3으로 바뀌어 기존에 생략된 **444행**에 두 판별기를 추가 실행해야 한다. 이것은 학습 오차의 원인이 확인됐다는 뜻이 아니라 별도의 검증 가설이다.

대안은 fold 0·3을 먼저 비교하고 통과하면 fold 4의 새 7개 변형 진단과 전체 5-fold를 요구한다. 성능·회귀 제한은 같은 사전 기준을 사용한다. `tools/score_encoder_confidence.py`, `tools/audit_encoder_confidence.py`, `tools/fresh_encoder_confidence.py`로 기존 학습 확대 실험과 분리했다. 모델 수·입력·가중치는 그대로이고 결합 계수와 정확한 계산 생략 경계만 바뀐다.

## 학습 확대 결과: 기각

`src/encoder_extended_experiment.py`에서 학습을 시작했다. fold 1의 그룹은 2,400개에서 **4,680개**로 늘었고 학습/검증 선박 중복 0척, 토큰 잘림 0개다. `tools/audit_encoder_extension.py`는 기존 v12의 저장 예측을 재현한 후 동일 후보에서 새 점수와 직접 비교한다. `tools/fresh_encoder_extension.py`는 별도 변형에서도 v12 전체 결합을 기준으로 비교한다.

약칭 회귀 14행을 먼저 살폈다. 그중 12행은 정답과 오답 후보의 톤수·선종·국적이 모두 같았다. 숫자 비교만 고쳐서 회복된다고 가정하지 않으며, 개별 행이 어떤 모델에서도 불가능하다고 단정하지 않는다.

두 fold 학습·검증을 완료했다. v12와 같은 후보·점수 결합에서 다음과 같았다.

| 두 fold 합산 지표 | v12 | 전체 그룹 학습 |
|---|---:|---:|
| testlike | **0.910593** | 0.910225 |
| hard | **0.858168** | 0.857369 |
| OOF | 0.995935 | 0.995935 |
| 단어 생략 한글 | **0.828767** | 0.826484 |

testlike 순증 **-0.000368**, 선박 bootstrap 95% 구간 **[-0.003446, +0.002976]**다. fold 1은 +0.000461, fold 2는 -0.001267이었다. 변형은 5행 회복·6행 손실, hard는 2행 회복·3행 손실이다. 사전 testlike +0.001 조건에 미달해 **나머지 fold·최종 학습·패키지 확대를 중단**했다. 5-fold 결과가 아니다. [두 fold 집계](../experiments/encoder_bge_full_v1_audit.json), [고정한 초기 결과](../experiments/encoder_bge_full_v1_screen_snapshot.json)

학습 확대 탈락에 따라 사전 등록한 40% 결합 대안을 실행했지만 아래와 같이 기각했다. 이번 작업에서 실제 대회 제출이나 test 분포 조회는 하지 않았다.

새 집계 도구의 v12 자기 비교는 전체 5-fold에서 **점수 순증 0, 예측 변경 0행**을 재현했다. 기존 v12 결과 파일을 덮어쓰지 않고 별도 `encoder_extension_selfcheck` 경로에서 확인했다. [검사 로그](../experiments/run_encoder_extension_selfcheck.log)

첫 fold 1의 학습·저장은 440.8초였다. 해당 fold에서만 v12 대비 testlike +0.000461, hard -0.001535였다. 이 중간 결과로 결론을 내리지 않고 fold 2까지 확인해 위와 같이 기각했다.

동일 모델 입력에 서로 다른 정답이 붙는 충돌도 집계했다. 같은 fold 안에서 모델 입력이 같은 19개 그룹·68행이 충돌했다. 정답 빈도를 아는 최적 선택기의 인공 testlike 상한은 비한글을 고정하면 0.996441로, 명시 충돌 손실은 약 0.003015다. 남은 오류 전부를 이런 충돌로 설명할 수는 없다. `arrival_year`를 구분 키에 추가하면 충돌이 줄지만 이는 입력 정보 점검일 뿐, 연도를 쓰는 모델의 개선을 검증한 것이 아니다. 후보 카탈로그의 관측되지 않은 대체 정답이나 실제 test의 모호성은 이 집계가 포착하지 못한다. [진단](../experiments/v12_ambiguity_audit.json)

## 40% 고정 결합 결과: 기각

fold 0·3에서 기존 생략 행 165개를 실제로 새로 판별했다. 두 fold testlike **0.913186 → 0.912465**(-0.000721), hard **0.863419 → 0.862684**, OOF 동일이었다. 단어 생략 한글은 0.810924 → 0.815126으로 올랐지만 생략+결측은 0.590336 → 0.579832로 내려갔다. 사전 +0.001 조건 미달로 확대하지 않았다. [집계](../experiments/encoder_confidence40_v1_audit.json)

40% 결합으로 정오가 바뀐 testlike 행은 모두 기존에 판별하던 행이었다. 두 판별기 의견이 달랐던 경우 6행 회복·8행 손실, 같았던 경우도 2행 회복·3행 손실이다. 의견 일치만으로 더 높은 비중을 주는 규칙의 근거도 충분하지 않았다. [진단](../experiments/encoder_confidence_disagreement_audit.json)

## 고정 시드 평균 실험

학습 범위·비중 확대가 모두 기각돼 기존과 같은 **2,400개 그룹·1 epoch·입력·학습률**에서 시드 2026 하나를 추가 학습한다. 데이터 선택은 기존 시드 42와 같은 그룹을 사용하고, LoRA 초기화·학습 순서·dropout의 시드만 2026으로 바꾼다. 여러 시드나 체크포인트를 탐색하지 않는다.

먼저 기존 시드 42와 새 시드 2026의 병합 가중치를 **FP32로 50:50 평균 → BF16 저장 → 재로딩**한다. Qwen/평균 BGE 각 12.5%와 v8 75% 결합을 유지해 모델 수·입력 형식·추론 경로를 바꾸지 않는다. [사전 프로토콜](../experiments/encoder_seed_average_protocol.json), `src/encoder_seed_average.py`.

가중치 평균이 기준을 통과하지 못하면 같은 두 시드의 **확률 평균**만 고정 대안으로 비교한다. v8 75% + Qwen 12.5% + 시드 42 BGE 6.25% + 시드 2026 BGE 6.25%이며, 추가 시드 학습은 하지 않는다. 모델 수·용량은 늘어나므로 채택 시 실제 ZIP·시간 검사도 요구한다. 이 대안 역시 첫 시드 결과를 확인하기 전에 [등록](../experiments/encoder_seed_probability_protocol.json)했다.

각 안은 fold 1·2 → fold 4의 새 변형 1,827행 → 전체 5-fold 순으로 진행하며 기존과 같은 성능·회귀 제한을 적용한다. 이전 두 실험을 본 뒤 정한 새 가설이므로 모든 분석은 계속 탐색적이다. 결과가 좋더라도 Public 상승을 보장하지 않는다.

## 최종 비교와 결정

| 비교안 | 평가 fold | 같은 fold의 v12 | 후보 testlike | 순증 | hard 순증 |
|---|---|---:|---:|---:|---:|
| 전체 적격 그룹 학습 | 1·2 | 0.910593 | 0.910225 | -0.000368 | -0.000799 |
| 신경망 비중 40% | 0·3 | 0.913186 | 0.912465 | -0.000721 | -0.000735 |
| 시드 42/2026 가중치 평균 | 1·2 | 0.910593 | 0.910417 | -0.000176 | **+0.002397** |
| 시드 42/2026 확률 평균 | 1·2 | 0.910593 | 0.908947 | -0.001646 | -0.000799 |

가중치 평균은 hard와 톤수가 남은 약칭을 개선했지만 생략+결측 손실이 늘어 testlike가 하락했다. hard 한 지표만 보고 채택하지 않았다. 확률 평균은 testlike·개별 fold·단어 생략 회귀 제한도 통과하지 못했다. 이 안의 선박 bootstrap 순증 구간은 [-0.003544, -0.000329]다. 전체 비교는 [요약 JSON](../experiments/encoder_followup_summary.json), [선택 기록](../experiments/encoder_followup_selection.json), [가중치 평균 집계](../experiments/encoder_seed_average_v1_audit.json), [확률 평균 집계](../experiments/encoder_seed_probability_v1_audit.json)에 저장했다.

**새로 채택한 모델은 없다.** 모든 안이 초기 조건에서 탈락했으므로 새 후보의 별도 변형 성능 측정·나머지 fold·최종 전체 학습·v13 ZIP 생성은 진행하지 않았다. fold 4의 1,827행 후보 캐시는 준비·검증했지만 새 후보를 평가한 결과가 아니다. `tools/release_encoder_followup.py` 등 후속 배포 도구는 조건 통과 시에만 실행하도록 구현했고 이번에는 호출되지 않았다. 이 도구의 새 ZIP 전체 실행 검사를 통과했다고 주장하지 않는다.

실행한 검사는 새 도구 구문 검사, 기존 v12 자기 비교의 전체 5-fold 점수·예측 일치, 새 시드 학습의 유한 손실, 가중치 평균의 키·모양·dtype·유한값 일치, 병합·BF16 저장·재로딩한 모델의 두 fold 평가다. 기존 v12 코드·가중치·ZIP·실제 Public 기록을 보존했다. 제출 횟수는 **9회 유지**, 목표 0.97은 미달이다.

## 다음 우선순위

이번 결과는 더 많은 업데이트·신경망 비중·한 번의 추가 시드 평균이 해당 조건에서 개선을 만들지 못했다는 근거다. 다른 학습법의 불가능성을 뜻하지 않는다. 같은 조건의 시드·비율 탐색은 우선순위를 낮춘다.

약칭 오답 212행에서 정답 후보의 톤수가 더 가까운 경우는 15행, 정답/오답 톤수가 같은 경우는 140행이었다. 숫자 비교만 바꾸는 방법보다는 **생략된 이름에서도 원문·음역·발음 정렬을 구별하는 학습 근거**와 검색 누락/재순위 오류의 분리를 다음 가설로 삼는다. 별도 Qwen 발음 정렬 입력이나 새로운 학습 증강은 이번에 구현·검증하지 않았으며 개선 효과도 미확인이다.

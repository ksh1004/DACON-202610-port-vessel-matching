# 이름 호환성과 선박 선택을 분리하는 후속 설계

2026-10-29. 실제 최고는 v12 Public **0.9065951735**, 서버591초, 제출9회다. 이번 작업은 새 오류 진단·논문 조사·실험 설계다. 새 모델의 성능을 측정하거나 개선을 달성한 결과가 아니다.

추천하는 다음 순서는 **모호한 음성 후보의 학습 압력 완화 → 문자 단위 이름 모델 → 공식 기록으로 학습한 조건부 입항 사전확률**이다. 처음부터 세 방법을 합치지 않고 각각의 추가 효과를 확인한다. 직전105/111/115개 특징 결합의 계수를 다시 찾는 실험은 반복하지 않는다.

## 이번에 실제로 추가 확인한 사실

`tools/audit_observation_ambiguity.py`로 기존5-fold v12 예측과 내부 학습 그룹을 조사했다. 이름 조건은 질의만으로 생성했던 Kanana 빔에 있는 영문 문자열이 정답과 오답 이름의 연속 단어 구간에 **동일하게** 존재하는 것이다. 제원 조건은 질의에 존재하는 국적·선종에 대해 두 후보의 카탈로그 값이 같고, GT/IGT가 관측된 경우 두 후보의GT도 같은 것이다. 제원 값이 질의와 정확히 맞는다는 조건은 아니다.

| 실제 한글 질의의 v12 오답 분류 | 단어 생략 | 생략+GT/IGT결측 |
|---|---:|---:|
| 오답 전체 | 212 | 504 |
| 같은 이름 구간 + 사용 가능한 후보 제원도 같음 | **102** | **247** |
| 같은 이름 구간, 후보 제원은 다름 | 71 | 131 |
| 후보 제원은 같고 위 이름 조건은 성립하지 않음 | 23 | 47 |
| 두 조건 모두 성립하지 않음 | 16 | 79 |

각 열의 네 분류 합계가 오답 수와 같음을 검사했다. 약칭 뒤에도 실제 한글이 남은 질의는 각1,184행이다. 비한글로 바뀐7행을 제외한 집계이므로 기존 원본 한글 기준1,191행·생략+결측506오답과 구분한다. [진단 결과와 사례](../experiments/observation_ambiguity_20261029.json)

기존 내부 신경망 학습9,254그룹 중 **384그룹(4.15%)**에서도 양성과 음성이 위 두 조건을 동시에 만족했다. 해당 음성 쌍은1,012개였다. 네 내부 분할은 같은 공식 자료를 겹쳐 사용하므로384개의 독립 선박을 뜻하지 않는다. 원래v12 최종 학습 자료와도 동일하지 않으며, 반복 사용한 학습 방식의 진단이다. 저장된 첫 후보가 각 학습 행의 실제 정답 ID인지 확인했다.

이는 **정보 이론적 상한이나 오답이 불가피하다는 증명은 아니다.** 캐시 빔이 부정확할 수 있고, 영문 전체 이름·입항연도·학습된 발생 사전확률은 여전히 단서가 될 수 있다. 다른 선박 ID는 개체 매칭에서 여전히 다른 정답이다. 특히 이런 후보를 같은 선박이라고 재라벨링해서는 안 된다.

그럼에도 오류의 약 절반에서 단순 이름 일치와 현재 제원이 후보를 구분하지 못한다는 관찰은 중요하다. 더 큰 범용 언어 모델이나 동일 특징 결합만으로 해결된다고 가정하기보다, **어떤 이름과 양립하는가**와 **그중 실제 어느 선박이 관측될 가능성이 높은가**를 분리할 이유가 있다.

## 1. 가장 먼저 할 작은 실험: 모호한 음성 후보의 학습 압력 완화

현재 신경망은 증강으로 구별 단어와 톤수가 사라져도 정답 하나에만 확률을 모으도록 학습한다. `케이엠티씨`를 보고 같은 제원의 `KMTC Seoul`과 `KMTC Yokohama`를 억지로 분리하게 되는 종류의 문제다. 이것이 최근 실패의 주원인이라고 확정한 것은 아니다.

첫 비교는 기존 판별기의 입력·2,400그룹·후보8개·시드·학습률·업데이트 수를 고정한다. 학습 질의와 정답/음성의 공식 이름·제원만으로 위 조건을 만족하는 음성을 정하고, 해당 음성에 대한 강제 분리 압력을 줄이는 손실을 시험한다. 원래 정답은 보존하고 전체 질의나 어려운 사례를 무작정 삭제하지 않는다.

대조군은 원래 손실과 **동일 개수의 임의 음성에 같은 완화를 적용한 손실**이다. 그래야 단순히 음성을 적게 쓴 효과와 모호성 판별의 효과를 구분할 수 있다. 모델 입력·추론에 정답 ID나 이 진단의 오답 목록을 넣지 않는다. 실제 평가에서는 기존 정답 행까지 포함한 전체 모집단을 비교한다.

관련 연구인 [Debiased Contrastive Learning, NeurIPS2020](https://papers.neurips.cc/paper_files/paper/2020/hash/63c3ddcc7b23daa1e42dc41f9a44a873-Abstract.html)은 잘못 구성된 음성이 표현 학습을 해칠 수 있음을 다룬다. 다만 그 논문의 같은 클래스 오염과 여기의 서로 다른 실제 선박은 다르다. 논문 손실을 그대로 적용하면 된다는 근거는 아니다.

[Partial-Label Learning with Conformal Candidate Cleaning, UAI2025](https://proceedings.mlr.press/v286/fuchs25a.html)는 모호한 후보 레이블을 다룬다. 이 대회에서는 공식 정답을 이미 알고 있으므로 그 PLL 설정·conformal 보장을 그대로 주장하지 않는다. 모호성을 별도 학습 대상으로 다룬다는 참고 근거다.

이 작은 비교에서 개선이 없으면 큰 모델과 복잡한 학습으로 확대하지 않는다.384그룹의 관찰만으로 전체0.97을 설명할 수 없으며, BGE12.5%만 바꾸는 경로의 구조적 한계도 그대로 남는다.

## 2. 이름 신호를 바꾸는 실험: ByT5로 보존된 철자·음절 대응 학습

기존 범용 Qwen/BGE 입력은 긴 기록과 음역 힌트를 함께 처리한다. 별도 이름 모델은 **한글 관측과 후보 영문의 보존된 구간**에 집중하도록 한다. 예를 들어 `루니`의 모음과 `Luni/Luna`, `펭슈하이`와 `Feng Xiu Hai/Feng Shou Hai`의 차이를 다룬다. 같은 이름 구간밖에 남지 않은 경우까지 이 모델이 구별한다고 가정하지 않는다.

범용 공개 [google/byt5-small](https://huggingface.co/google/byt5-small)을 첫 후보로 권한다. [ByT5 논문, TACL2022](https://aclanthology.org/2022.tacl-1.17/)은 바이트 표현의 잡음 강건성과 철자·발음에 민감한 작업을 실제 평가했다. 이 대회의 한국어 선박명 개선은 검증하지 않은 새로운 적용이다. 최신 모델이라는 이유로 고른 것이 아니라 짧은 문자열의 표현을 바꾸기 위한 후보이며, 문헌에서만 언급했던 방법을 구체화한 것이다.

2026-10-29 확인한 고정 revision은 `68377bdc18a2ffec8a0533fef03b1c513a4dd49d`, Apache-2.0이다. config로 로컬4.57.6의T5 클래스를 메타 장치에서 구성해299,637,760개 매개변수를 확인했다. 공개PyTorch 파일은1,198,627,927바이트다. 바이트 토크나이저의 철자 구분·복원을 확인했지만 이는 성능 검사가 아니다. **가중치를 다운로드하거나 로딩·학습·시간 측정한 것은 아니다.** 모델 카드상 사전학습만 된 모델이므로 미세조정이 필요하다. [정적 호환성 기록](../experiments/byt5_feasibility_20261029.json)

학습에는 공식 한글–영문 이름 쌍을 사용하고 메타데이터는 이름 모델에서 제외한다. 약칭을 주고 보이지 않는 전체 영문명을 복원하도록 강제하지 않는다. 실제 관측과 대응되는 영문 구간을 고신뢰 정렬에서 얻고, 여러 구간이 양립하면 그 불확실성을 보존한다. 정렬된 구간도 약한 레이블이므로 품질 확인 없이 대량 학습하지 않는다.

이름이 다른 데 제원이 비슷한 후보를 구분하는 표본과, 이름이 같은 구간을 공유해 구분할 수 없는 표본을 따로 측정한다. 기존 카탈로그 합성 음역 사전 적응이나37×37 단문자 비용을 다시 학습하는 것과 구분한다. 기존 Kanana 역방향 점수도 공개 고정 모델의 전체 이름 확률이었으며, 이 안은 실제 공식 쌍으로 학습하는 별도 바이트 이름 모델이다.

## 3. 이름이 양립할 때의 선택: 공식 기록으로 조건부 입항 사전확률 학습

동일한 관측 이름과 제원으로 여러 선박이 양립하면 이름 모델의 높은 확신만으로 해결하기 어렵다. 공식 영문 기록11,031행도 활용해 **이 입력 조건에서 어떤 후보 속성을 가진 선박이 입항 기록에 나타나는가**를 별도로 추정하는 안을 검토한다.

기존v8에도 선종·국적의 주변 사전확률이 있고, 최근 토큰 통계도 일부 강건성 개선을 보였다. 따라서 사전확률 자체를 새 방법이라고 주장하지 않는다. 새로운 비교 대상은 입항연도·질의 선종/국적·결측과 후보 크기·DWT/GT·선종/국적의 **공동 분포**다. 공통 이름 토큰을 쓴다면 서로 다른 여러 학습 선박에서 지원되는 값만 허용한다.

공식 정답 쌍과 공식 카탈로그 배경 쌍의 밀도비를 학습하는 작은 모델로 시작할 수 있다. 크기 등은 학습 자료로 정한 구간으로 묶고 통계의 지원 선박 수를 제한해 단일 선박을 가리키는 조합 암기를 피한다. 완전한 선박명·ID·호출부호·같은 선박 조회표는 입력과 저장 객체에서 제외한다. 외부 검증 선박을 통째로 빼서 범용 속성의 일반화를 확인하며, 이름 구간이 같은 후보 사이의 구분 가능성도 따로 본다. 과거의 원시연도 추가·10개 토큰 집계와 동일한 비교로 만들지 않아야 한다.

이 접근도 이미 같은 속성을 가진 자매선을 모두 해결할 수 없다. 조건부 사전확률은 외부 선박 사실이나 실제test 빈도가 아니며, 공식 학습 모집단에서 추정하는 통계다. 개선 여부를 확인한 뒤에만 이름 점수와 결합한다.

## 검증과 실행 판단

이 문서는 이번 진단 결과를 본 뒤 작성한 **새 제안**이며 사전 등록된 성능 실험이 아니다. 새 학습을 시작할 때 아래 범위와 수치를 먼저 고정한다.

- 대조군은 실제 최고v12다. 이전0·2fold의 결과만 계속 최적화하지 않고, 예를 들어fold1·4와 새 시드의 고정 변형을 사용한다. 이 선박들도 과거 실험에 등장했으므로 완전 미관찰 검증이라고 부르지 않는다.
- 작은 실험은 계열마다 독립 비교하고, 전체testlike·hard·원본·톤수 있는 약칭·톤수 없는 약칭을 함께 본다. 이름 점수나 오답 일부만의 개선을 대회 정확도 향상으로 환산하지 않는다.
- 제안하는 초기 확대 조건은 v12 대비testlike+0.003 이상, 각fold-0.002 이상, 단어 생략/hard 한글-0.002 이상, clean 기존 정답 손실1행 이하와 해당 대조군 대비 추가 효과다. 이후 다른fold 진단과 전체5-fold+0.005·4개fold 개선을 요구한다. 아직 어떤 후보도 이를 통과한 것이 아니다.
- 결합 학습에 새로 학습한 모델 점수를 넣으면 해당 외부 검증 선박을 제외한 내부 교차 예측이 필요하다. 이미 있는 내부Qwen/BGE 점수로 새ByT5의 내부 점수를 대신할 수 없다.
- 모든 새 추론 구조에서 실제 행 독립·단독/부분집합·후보 순서·실행시간·패키지 검사를 다시 한다. 기존25% 계산 생략 경계를 다른 선택기에 그대로 적용하지 않는다.

목표0.97까지 실제 Public 가중 오차의 약67.9%를 회복해야 한다. 위 연구가 그 개선을 보장하지는 않는다. 이번에 얻은 것은 실패한 결합을 반복하기보다 **학습 손실·이름 표현·조건부 발생 통계 중 어디에 새 근거가 필요한지**를 나눌 수 있는 진단이다.

공식train/catalog와 공개 범용 가중치만 사용하는 범위를 유지한다. 호출부호·동일 선박 조회 제외 방침도 유지한다. [공식 규칙](https://dacon.io/competitions/official/236771/overview/rules)

# 내부 교차 예측으로 신경망 정보를 보존하는 최종 결합 (2026-10-29)

현재 상태: **내부 판별기8개 학습·평가 완료, 사전 등록한4계열·8선택 구성 모두 초기 기준 미달로 기각**. 새 최종 모델·ZIP·실제 제출 없이 v12를 유지한다. 실제 최고는 v12 Public0.9065951735·591초·제출9회다. 목표0.97은 달성하지 못했다. [전체 결산](../experiments/nested_iteration_20261029.json), [고정 순서의 선택 결과](../experiments/nested_family_selection_20261029.json)

## 목적과 고정한 설계

[이전 직접 재순위 실험](reverse_name_ranking_20261028.md)은 역방향 이름 점수의 추가 신호를 확인했지만 기존 지도학습 Qwen/BGE의 판단을 대체하면서 v12보다 하락했다. 이번에는 그 신호를 보존한 상태에서 최종 선택을 학습한다.

- 외부 검증은 기존 fold0·2다. 각 외부 학습 집합을 정답 선박 ID 기준으로 다시2분할한다. 범주 매퍼·후보 검색·LightGBM 음성 채굴기·Qwen/BGE 모두 내부 학습 선박만으로 적합한다.
- 내부 판별기는 공개 원본 Qwen3-Reranker-0.6B와 BGE-reranker-v2-m3에서 시작한다. 원래의 evidence/발음 키 입력, 최대2,400그룹·정답+엄격한 음성5개+어휘 음성2개·LoRA8·1epoch·시드42를 유지한다. 외부 학습 전체로 학습한 모델을 내부 예측에 사용하지 않는다.
- 결합기 학습 자료는 내부 검증 선박의 원본·seed7 증강4개·고정 testlike3개다. 신경망이 해당 선박을 보지 않은 점수를 넣는다. 실제 한글이며 상위20에 정답이 있는 학습 그룹만 사용한다. 후보에 정답을 추가하지 않는다.
- 원본/GT결측/단어생략/생략+결측 가중치는0.44/0.14/0.23/0.19, 증강 각0.10이다. 실제 Public 분포로 확인한 값이 아니라 기존 탐색 지표와 hard 강건성을 위한 고정 학습 구성이다.
- 원시78개에 LightGBM·Qwen·BGE의 확률/로그확률/순위/점수차/엔트로피/상위확률/상위차와 고정 혼합·의견 일치 특징27개를 추가한다. 최종 LambdaRank는105개 특징·150회·기존 고정 파라미터다. 동일 자료·가중치의 원시78개 대조군을 함께 비교한다.
- 후보는 `v12확률50% + 학습 결합기50%`와 결합기 직접 선택이다. 조건을 통과하면50:50을 우선한다. v12의 기준 확률은 누락된 신경망 점수도 실제 계산한다. 학습형 선택에 기존25% 생략 경계를 적용하지 않는다.

[사전 조건](../experiments/nested_combiner_v1_protocol.json), [소스·입력 해시](../experiments/nested_combiner_lock.json). 두 후보가 탈락할 때만 역방향6개 특징을 추가하는 별도 [조건부 실험](../experiments/nested_combiner_reverse_v1_protocol.json)도 미리 등록했다. 그 대조군은105개 특징 모델이며 계수 탐색은 하지 않는다.

모델 학습 중에는 검증 fold0·2를 제외한 학습 자료만으로 이름 토큰 통계의 가능성도 확인했다. 첫 토큰을 공유하는 서로 다른3척 이상 집단242개가 학습 선박의 약50.4%를 포함했다. 기존 두 실험이 모두 탈락할 경우에만 실행하는 [토큰 사전확률 추가](../experiments/nested_combiner_token_prior_v1_protocol.json)를 새 결합 성능 확인 전에 별도로 고정했다. [학습 자료만의 집계](../experiments/training_prefix_feasibility_20261029.json)

이 대안은 원래105개에 이름의 첫/마지막 알파벳 토큰별 지원 선박 수·카탈로그 대비 출현 비율·국적/선종/공동 범주의 로그 우도비10개를 더한다. 같은 선박은 한 번만 세고 서로 다른3척 이상인 토큰만 사용하며 평활 가상 횟수는5다. 내부 학습 자료의 영문명 기록도 통계에 활용한다. 객체에는 선박 ID/호출부호 대응표를 저장하지 않는다. 실제 결과는 아래와 같다.

동일 자료의 원시78개 대조군 자체가 더 좋을 가능성도 성능 확인 전에 [별도 후보](../experiments/nested_raw78_fallback_v1_protocol.json)로 고정했다. 이는 신경망 특징의 효과가 아니라 학습 자료·가중치·선택기의 공동 효과이며, 같은 v12 대비 최소 개선·퇴행 제한을 요구한다. [고정한 순서](../experiments/nested_family_protocol_20261029.json)는105개 신경망 결합→원시78개→역방향 추가→토큰 통계 추가다. 첫 초기 통과 후보를 잠근 뒤 별도 진단·전체 검증을 진행하며, 그 후 실패해도 다음 계열을 탐색하지 않는다.

## 준비와 검증

네 내부 분할의 판별기 그룹은2,400/2,094/2,400/2,360개, 결합기 그룹은3,335/4,101/3,756/3,839개로 총15,031개다. 각 분할의 Qwen/BGE를 새로 학습해8개 모델의 병합·BF16 저장·재로딩·내부 검증 점수 계산을 완료했다. 내부 학습·내부 검증·외부 검증의 양성 선박 중복은0이다. ID·호출부호를 바꿔도 인코딩이 같고, 후보 순서 변경·점수 전체 이동·균일 점수에서 결합 특징의 불변성과 확률 통계를 확인했다. [준비 검사](../experiments/nested_combiner_setup_checks.json)

기존 외부 fold0의 신경망 점수를 전 행에 대해 계산했다. BGE의 기존 활성292행은 완전 일치했다. Qwen은292행 중5행에서 후보 하나의 BF16 수준 점수 차이(최대0.125)가 있었다. 현재 배포 모델에서 해당5행을 다시 계산하고 역순으로 실행하면 캐시와 정확히 같았으며, 기존 v12 선택은 외부1,398행 모두 같았다. [수치 진단](../experiments/nested_outer0_precision_diagnostic.json), [반복 검사](../experiments/nested_outer0_runtime_checks.json)

이 차이를 숨기지 않고 소스 수정 전 스냅샷과 변경 이유를 기록했다. 기존 로그와 비트 단위 점수 일치 대신 모든 기준 예측 일치를 요구하며 수치 차이를 보존한다. 학습 파라미터·성능 기준은 바꾸지 않았고 아직 새 판별기·결합기의 검증 결과를 보지 않은 시점의 수정이다. 여기서 기준 확률 복원은 생략 분포를 임의 근사하지 않고 실제 모델로 계산한다는 뜻이다.

외부 fold2도 BGE 기존 활성243행은 완전 일치했고 Qwen238/243행이 완전 일치했다. 나머지5행의 최대 차이는0.125였고 두 fold 전체2,658행의 v12 예측은 모두 보존됐다. 실제 한글2,651행·53,020후보에 신경망 점수를 계산했다. 일부 증강 이름이 실제 비한글인 경우 기존 경로를 유지하며 불필요한 과거 신경망 점수 비교만 제외했다. 두 수정 모두 비교 함수 안의 변경이며 학습·특징·조건 함수가 동일함을 AST로 확인했다. [수정 검사](../experiments/nested_comparison_fix_checks.json)

저장한105개 특징 결합기와78개 특징 대조군을 다시 불러와 두 fold의53,020후보 점수가 저장값과 정확히 같은지 확인했다. 전체 후보 행 셔플·단독 행 예측·모델별64그룹의 후보 순서 변경도 완전 일치했다. 이는 고정한 전문가 점수와 선택기의 검사이며 새 제출 패키지 전체 실행 검사를 뜻하지 않는다. [저장·행 독립 검사](../experiments/nested_combiner_v1_head_checks.json)

## 확대 기준과 한계

외부 두 fold에서 v12 대비 testlike 최소+0.003, 최악 fold-0.002 이상, hard 한글/단어 생략-0.002 이상, clean 기존 정답 손실1행 이하, 동일 대조군 대비+0.001을 요구한다. 통과 후 별도 fold3 진단과 전체5-fold +0.005·4개fold 개선 등을 확인한다. 최종 전체 학습·패키지는 그 이후다.

외부 비교에는 역사적 v8 검색 매퍼 예외가 남아 있으며, 내부 학습에서 이를 재사용하지 않는다. LightGBM 프록시는 한글 원본·증강으로 학습한 단일 모델이고 v8 앙상블이 아니다. v12는 고정 추론 앵커로만 사용한다. 기존5-fold 신경망 점수를 재분할해 결합기 학습 특징으로 넣지 않는다. 기존 Kanana의 고정 few-shot 영향은 제외 민감도 분석과 구분한다. 호출부호·동일 선박 조회·외부 선박 데이터·실제 test 분포는 사용하지 않는다.

이번에는 초기 통과 후보가 없어 별도 fold3 후보 진단·전체5-fold 후보 평가·최종 전체 학습·추가 패키지 검사를 진행하지 않았다. fold1·3·4의 내부 데이터 준비는 완료했지만 해당 fold의 새 신경망 학습이나 후보 검증을 수행한 것은 아니다. 결과를 확인한 뒤 혼합 계수·학습 횟수·선택 조건을 바꿔 재탐색하지 않았다.

입력과 소스 고정 해시, 기존 v12 소스13개와ZIP 전체 SHA256을 결산 도구로 확인한다. 내부 교차 예측 자료·8개 모델·역방향 점수·검증 예측은 보존해 이후 별도로 설계한 실험에서 같은 비용을 반복하지 않도록 했다. 토큰 통계는 추가 정보의 가능성을 보였지만, 이 결과만으로 v12 토큰 통계 혼합이나 조건부 적용이 개선된다고 주장할 수 없다. 후속은 약칭에 톤수가 있는 경우와 없는 경우의 회복·손실 원인을 구분하고, 반복된 두 fold 외의 진단을 포함해 설계해야 한다.

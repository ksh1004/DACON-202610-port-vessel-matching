# 공식 카탈로그 새 이름으로 음역 사전 적응 (2026-10-28)

현재 확인된 Public 최고는 v12 **0.9065951735 / 9분 51초**다. 이 실험은 아직 Public 성능이 없다. [이전 A1·A2](focused_training_20261028.md)는 각각 별도 진단·초기 개선 폭 조건에 미달해 채택하지 않았다.

## 학습 구성

공식 카탈로그에서 공식 train의 모든 정답 선박 ID와 같은 전체 이름을 제외한 3,000개 이름의 목록을 먼저 고정했다. 공개 Kanana 가중치로 앞 1,536개 이름의 한글 음역을 두 개씩 생성했다. 외부 선박 사실·사전·조회는 사용하지 않는다. 생성 문장은 확정된 발음 정답이 아니다.

숫자 보존, 한글 포함, 라틴 문자 제외, 기존 자음 키의 정규화 편집 유사도 0.9 이상, 서로 다른 원문을 가리키는 같은 한글 이름 제외로 걸렀다. 다른 선박 이름을 먼저 뽑은 뒤 두 번째 음역을 채워 **1,200그룹 / 최소 600개 서로 다른 이름**을 고정한다. 단어를 지우기 전 전체 이름에 품질 조건을 적용하며, 이번 사전 적응에서는 단어 생략을 하지 않는다.

질의와 문서의 톤수·국가·선종은 모두 null이고 영문 음역 beam도 비운다. 양성은 해당 원문 이름이고, 음성은 공식 카탈로그의 가까운 이름 5개와 발음 키가 가까운 이름 2개다. 같은 전체 영문 이름은 음성에서 제외한다. 선박 ID는 오프라인 정답 연결에만 쓰며 모델 입력과 제출 시 조회에 쓰지 않는다.

공개 BGE에서 1,200개 합성 그룹을 1 epoch·학습률 5e-5로 사전 적응한다. 그 병합 가중치에서 각 fold의 **기존 v12 2,400개 실제 학습 그룹을 그대로** 1 epoch·학습률 1e-4로 학습한다. LoRA rank8/alpha16/dropout0.05, 시드42, 그룹당8쌍, 배치2그룹, 최대256토큰을 고정한다. 합성 양성이 모든 실제 train 선박과 겹치지 않아 공통 사전 적응 가중치를 fold마다 사용할 수 있다.

이번 구성은 실제 그룹 예산을 유지하면서 공통 사전 적응 600업데이트를 추가한다. 앞선 A1처럼 총 업데이트까지 같은 대조는 아니므로, 효과가 나더라도 합성 데이터만의 효과와 추가 업데이트의 효과를 분리해 입증한 것은 아니다. 사전 적응은 88.1초 걸렸고 그룹 잘림은 0개였다. 입력 메타데이터 결측과 ID·호출부호 불변 검사를 통과했다.

## 채택 조건

[프로토콜](../experiments/catalog_warm_protocol.json)을 새 모델 학습 전에 저장했다. v8 75% + 기존 Qwen 12.5% + 새 BGE 12.5%를 유지한다.

- fold 0·2: testlike +0.002 이상, 최저 fold -0.002 이상, hard 한글·단어 생략 한글 하락 최대0.002, 원본 정답 손실 최대1행.
- 통과하면 fold 3의 별도 7종 변형 진단: few-shot 선박 제외, 학습 fold 전용 검색·매퍼, 평균 하락 최대0.002. 이 7종 진단으로 A1을 평가한 fold 4는 재사용하지 않는다. fold 3 자체는 과거 CV에 포함됐으므로 완전히 새로운 실측 검증은 아니다.
- 통과하면 전체5-fold: testlike +0.003 이상, 4/5 fold 개선, hard 한글 하락 최대0.001, 단어 생략 한글 하락 최대0.002, OOF 하락 최대0.0006.

기존 CV는 반복 사용한 탐색용 합성 검증이고 과거 v8 평가 후보 매퍼 예외가 남는다. 조건을 통과한 후보만 최종 학습·별도 패키지·실행 검사를 한다. 호출부호·동일 선박 조회는 제외하며 대회 업로드는 하지 않는다.

별도 fold3 변형 진단·나머지 fold·최종 전체 학습·새 ZIP은 실행하지 않았다. 조건부 배포 도구는 구문 검사만 했으며 새 패키지 실행 검사 통과로 보고하지 않는다. v12 코드13개·실제 Public 기록·ZIP 크기가 유지됨을 확인했다. 새로운 학습 예시를 더한 이 구성으로 개선을 입증하지 못했으며 합성 음역 전체가 불가능하다는 결론은 아니다.

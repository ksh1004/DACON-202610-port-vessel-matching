# v10 이후 후보 판별기 개선

작업일: 2026-10-27. 목표는 Public 0.97이며 호출부호 조회·train/test 동일 선박 조회는 제외한다. 기존 v10과 제출 ZIP은 보존한다. 실제 test 조회나 대회 제출은 하지 않는다.

**후속 실제 결과(2026-10-27 사용자 보고): v11 Public 0.9039635945, 서버 9분 31초.** 이전의 미제출·Public 미측정 문구는 에이전트의 패키지 준비 당시 상태다. 사용자가 이후 제출했으며 현재 기록된 제출은 총 8회다. 로컬 testlike 대비 약 -0.0048이다.

## 전체 5-fold 결과와 채택 판단

5개 fold 평가를 완료했다. 사전에 정한 조건을 통과한 새 판별기 단독을 **v11 검증 후보**로 선택했다. 최종 모델 학습과 ZIP 실행·행 독립성·무결성 검사까지 완료했다. **목표 0.97은 미달이며 Public은 미측정**이다.

| 지표 | 기존 v10 | v11 단독 | 고정 두 판별기 평균 |
|---|---:|---:|---:|
| testlike | 0.907375 | **0.908762** | 0.909332 |
| hard | 0.850294 | **0.854115** | 0.854408 |
| 원본 OOF | 0.997693 | **0.997693** | 0.997693 |
| v10 대비 testlike 순증 | — | **+0.001387** | +0.001957 |
| testlike 순증 fold 수 | — | **3/5** | 2/5 |

고정 평균은 평균 점수가 더 높았지만 5개 중 3개 이상 fold 순증 조건을 통과하지 못했다. 조건을 사후에 바꾸지 않고 단독 모델을 선택했다. [선택 기준 적용 결과](../experiments/pair_iteration_selection.json)

단독 순증의 선박 paired bootstrap 95% 구간은 **[-0.003306, +0.005973]**, 평균은 [-0.001455, +0.005550]로 모두 0을 포함한다. v11의 fold별 순증은 +0.006790 / -0.004513 / +0.001833 / +0.007576 / -0.004069다. Few-shot 선박 전체를 제외해도 v10 0.907055 → v11 0.908486으로 평균 순증은 유지됐다. 그러나 반복 사용한 검증 세트, 기존 v8 검색 매퍼 예외, 합성 노이즈 구성 가정이 남는다. **확정적인 Public 개선이나 목표 0.97 달성으로 선언하지 않는다.** [전체 집계](../experiments/neural_evidence_v1_audit.json)

한글 시나리오별 정확도는 톤수 결측 0.979849 → 0.973971, 단어 생략 0.812762 → 0.827036, 둘 다 0.554996 → 0.552477이다. 원본은 동일하다. 이름 생략만 있는 경우의 이득이 나머지 두 시나리오의 손실을 상쇄했으며, 모든 노이즈가 개선된 것은 아니다.

원본 OOF의 정답 회복·손실은 모두 0행이다. hard는 47행 회복·34행 손실로 순증 13행, testlike 변형은 84행 회복·77행 손실로 순증 7행이다. 시나리오별 순증은 톤수 결측 -7행 / 단어 생략 +17행 / 둘 다 -3행이다. [변화 집계](../experiments/evidence_change_audit.json), [바뀐 예측 654행의 입력·정답·이전/신규 선박명](../experiments/evidence_changes.csv). 마지막 CSV에는 오답에서 다른 오답으로 바뀐 행도 구분해 포함한다.

## 출발점

v10의 5-fold testlike 0.907375, hard 0.850294, OOF 0.997693은 v8보다 높았지만, 5개 중 1개 fold에서 하락했고 순증의 bootstrap 구간은 0을 포함했다. 큰 개선으로 판단하지 않는다.

학습 입력을 직접 확인했다. 기존 2,400개 그룹, 19,200개 쌍의 길이는 최소 165 / 중앙값 188 / 최대 225토큰으로, 256토큰에서 잘린 입력은 0개다. 입력 잘림을 개선 원인으로 가정하지 않는다. 기존 음성 후보 7개 중 4개가 무작위였고, 기존 Kanana 음역은 신경망 입력에서 빠져 있었다.

## 사전에 정한 새 학습 구성

- 공식 범용 Qwen3-Reranker-0.6B 가중치, LoRA rank 8 / alpha 16 / dropout 0.05, 학습률 1e-4, 2,400개 그룹, 고정 1 epoch, 시드 42, 최대 256토큰은 유지한다.
- `src/pair_evidence.py`: 기록 이름에서 기존 Kanana가 독립적으로 생성한 최대 4개 영문 음역을 함께 제공한다. 카탈로그 정답에서 복사한 이름이나 ID는 넣지 않는다. 지시문은 짧게 정리한다.
- `src/neural_reranker.py --negative-mode hard`: 학습 fold에서만 학습한 LightGBM 점수가 가장 높은 음성 5개와 나머지 문자열 혼동 음성 2개를 고른다. 외부 검증 점수나 정답으로 학습 음성을 선택하지 않는다.
- 기존과 동일한 v8 검증 후보에서 상위 20개를 판별하고 기존 75% + 신경망 25%로 결합한다. 검증 정답을 후보에 보강하지 않는다. 실제 입력 이름이 비한글이면 기존 경로를 유지한다.

정답을 고르는 방식에 영향을 주는 두 변경을 함께 시험한다. 성공하더라도 각 변경의 독립적인 기여로 나누어 해석하지 않는다. 새 학습은 모두 checkpointing을 끄며 기존 v10 일부 fold와는 연산 경로도 다르다.

첫 fold 점수가 나오기 전에 비교안을 두 개로 고정했다. 새 판별기만 25% 사용하는 안과, v8 75% + v10 신경망 12.5% + 새 신경망 12.5%의 동일 비율 평균이다. 가중치 탐색은 하지 않는다. 단독 모델이 기준을 통과하면 우선하고, 고정 평균도 같은 기준에서 비교한다. 두 안을 비교하므로 선택 편향이 추가될 수 있음을 기록한다.

## 확대 기준

먼저 fold 3과 0을 평가한다. v10에서 나빴던 fold와 좋았던 fold를 함께 사용한다. 이미 본 검증 세트를 재사용하므로 이 단계는 탐색이며 독립적인 최종 검증은 아니다.

- 두 fold를 합친 testlike가 v10보다 최소 +0.001 개선.
- 각 fold testlike 순증은 -0.002 이상.
- hard 한글 평균 순증은 -0.002 이상.
- 기존 원본 OOF 정답 중 새 모델이 잃는 행은 최대 1개.

기준은 학습 결과를 보기 전에 [pair_iteration_protocol.json](../experiments/pair_iteration_protocol.json)에 저장했다. 통과하면 나머지 3개 fold를 평가한다. 한두 fold만으로 전체 성능을 주장하거나 최종 모델을 교체하지 않는다.

나머지 fold 결과가 나오기 전에 최종 후보 기준도 저장했다. 전체 testlike는 v10 대비 +0.001 이상, hard 한글 하락은 최대 0.002, 원본 OOF 하락은 최대 0.0006이며 5개 중 3개 이상 fold에서 testlike 순증이어야 한다. 별도 스트레스 평균 하락도 최대 0.002다. 통과해도 통계적으로 확정된 개선이나 0.97 달성을 뜻하지 않는다.

## 별도 스트레스 진단

`tools/pair_fresh_stress.py`로 fold 3의 검증 선박에 새 변형을 적용한다. Few-shot 예시 선박 전체를 제외하고, 범주 매퍼·후보 검색·LightGBM 기준 모델은 학습 fold만 사용한다.

- 총톤수만 결측 / 국제총톤수만 결측.
- 총톤수는 0.5배 또는 1.5배지만 국제총톤수는 유지하는 모순.
- 첫 단어 또는 마지막 단어만 남기되 톤수 유지.
- 첫 단어 또는 마지막 단어만 남기고 두 톤수 모두 결측.

단어 생략이 실제로 일어난 행과 원래 한 단어여서 바뀌지 않은 행은 별도 집계한다. 비교 모델 모두 동일 후보·동일 엄격 LightGBM 기준에서 고정 25% 결합을 사용한다. 이 7개 시나리오 단순 평균은 기존 testlike나 공식 지표가 아니다. 새 모델의 평균이 v10보다 -0.002 넘게 떨어지면 확대하지 않는다.

## 중간 검증 기록

입력 검사에서 새 fold 0·3 모두 256토큰에 도달한 학습 쌍은 0개였다. ID·호출부호를 바꿔도 입력 토큰이 같았으며 중복 음역은 제거된다. 새 비교 도구는 기존 v10을 자기 자신과 비교했을 때 단독/평균 두 안 모두 순증 0을 재현했다. 검증 과정에서 기준 확률의 float32/float64 정규화 경로 차이를 발견해 기존 학습·평가와 같은 float64로 맞췄다.

첫 fold 3의 한글 testlike는 v10 0.850823 → 새 모델 0.861646, hard 한글은 0.870370 → 0.858025였다. 고정 평균은 한글 testlike 0.858230 / hard 한글 0.872428이었다. 당시에는 한 fold로 채택하지 않고 fold 0과 별도 스트레스 평가를 이어갔다.

두 fold 0·3의 평가를 완료했다. 다음은 해당 두 fold만의 값이며 전체 5-fold 성능이 아니다.

| 두 fold 지표 | v10 | 새 판별기 | 동일 비율 평균 |
|---|---:|---:|---:|
| testlike | 0.902568 | 0.909759 | 0.909995 |
| hard | 0.856066 | 0.857537 | 0.861949 |
| OOF | 0.998112 | 0.998112 | 0.998112 |
| v10 대비 testlike 순증 | — | +0.007191 | +0.007426 |

두 안 모두 사전 확대 기준을 통과했다. 순증의 선박 bootstrap 95% 구간은 단독 [+0.000951, +0.014344], 평균 [+0.002412, +0.013261]이었다. 평균 점수와 신뢰 구간은 이 두 fold의 탐색 결과에 한정되며, 나머지 fold와 별도 스트레스 결과를 기다린다.

### 고정 25% 결합의 낙관적 한계

`tools/probe_pair_capacity.py`로, 상위 20개 중 정답에 신경망 확률을 100% 부여하는 이상적인 선택기를 계산했다. 비한글 입력은 v8 그대로 유지한다. 고정 신경망 25% 결합의 testlike는 **0.9736**, 50% 이상에서는 **0.9888**이다. 실제 모델의 점수가 아니며 검증 후보와 합성 노이즈 가정에 의존한다. 현재 구조로 0.97이 수학적으로 배제되지는 않지만, 25% 결합에서 회복 가능한 오차의 약 95%를 실제로 해결해야 한다. 단순한 소폭 평균 개선과는 요구 수준이 다르다. [오라클 근거](../experiments/pair_blend_oracle.json)

아래 중간 결과를 포함한 5-fold 학습·평가를 완료했다. 최종 전체 결과는 문서 상단을 따른다.

세 번째 fold 1의 단독 한글 testlike는 v10 0.863289 → 0.856842로 하락했다. fold 0·1·3 합산 순증은 단독 +0.003401, 고정 평균 +0.004514로 두 fold 결과보다 줄었다. 나머지 fold를 같은 설정으로 계속 평가한다.

## 재현 및 로컬 패키지 처리

학습·평가·추론 소스와 기준은 저장된 protocol·audit에 연결한다. 다음 명령은 실제 test를 읽거나 대회에 제출하지 않는다. 새 스트레스 음역 생성과 GPU 평가를 다른 학습과 동시에 실행하지 않는다.

```powershell
# 기존 strict_han_v1 학습 fold 후보 캐시가 필요하다.
.venv/Scripts/python.exe -m src.neural_reranker --fold 0 --tag neural_evidence_v1 --recipe evidence --negative-mode hard --max-groups 2400 --no-checkpoint --skip-pretrained --merge-eval --bound-prune --v8-oof-eval
# 같은 고정 설정으로 나머지 fold도 수행한다.
.venv/Scripts/python.exe -m tools.audit_pair_iteration --tag neural_evidence_v1
.venv/Scripts/python.exe -m tools.pair_fresh_stress --fold 3 --tag neural_evidence_v1
.venv/Scripts/python.exe -m tools.select_pair_iteration
# 5-fold 기준 통과 때에만: OOF 재현 검사 → 최종 학습 → ZIP 실행·행 독립·CRC 검사.
.venv/Scripts/python.exe -m tools.release_pair_iteration
```

## 최종 모델·제출 ZIP

`tools/check_pair_views_runtime.py --variant evidence_only` 검사 통과: 병합·저장·재로딩한 신경망 logits가 저장 OOF와 정확히 같았으며, 배포 블렌딩·그룹 분할·셔플·단독 행 점수도 일치했다. [실행 로그](../experiments/run_v11_runtime.log)

공식 전체 train 전용 혼동 후보 모델로 준비한 2,400개 그룹을 사용해 최종 v11 학습·병합·저장을 마쳤다(로컬 9.85분). 산출물은 [ranker_v11_pairviews](../experiments/artifacts/ranker_v11_pairviews), [설정·데이터/소스 해시](../experiments/artifacts/ranker_v11_pairviews/pair_views.json)다. 단독 evidence 모델 하나만 사용하며 기존 v10 모델은 보존했다.

최종 ZIP: **[dist/v11_pairviews.zip](../dist/v11_pairviews.zip)**, 5,833,585,950 bytes(5.83GB), 파일 43개. [배포·검사 메타데이터](../experiments/release_v11_pairviews.json)에 SHA-256과 결과를 기록했다. 추론 소스 해시와 고정한 5-fold 결과의 해시가 실제 패키지와 일치한다. 생성된 진입점에서 호출부호 조회 코드 자체를 제외했고, 조회표·학습용 어댑터도 넣지 않았다. 모델 카드·라이선스·수정 내역을 포함했다.

# 후보 조건부 역방향 음역과 직접 재순위 실험 (2026-10-28~29)

현재 상태: **전체 이름·생략 구간 합산 네 후보와 4B 공동 비교 교사 진단 모두 기각**. v12 유지, 새 제출 패키지·실제 제출 없음.

사용자가 승인한 [연구 제안](research_097_redesign_20261028.md)의 첫 단계다. 고정 Kanana에 공식 후보 영문명을 주고, 실제 관측 한글명 토큰의 조건부 확률을 계산한다. 새로운 영문명을 생성하거나 외부 선박 사실을 조회하지 않는다. `call_sign`과 동일 선박 조회는 제외한다.

## 고정한 비교

- 학습은 각 검증 fold의 선박을 모두 제외한다. 기존 v12와 동일한 순서·자격 조건에서 처음 2,400그룹을 선택한다. 각 그룹은 정답과 strict 학습 fold LightGBM의 상위 음성19개이며 후보는 카탈로그 인덱스 순으로 정렬한다.
- 특징은 원래 전체 검색 후보에서 계산한 78개에 역방향 log probability 합·평균·종료 토큰·최고점과 차이·동점 공통 순위·토큰 수6개를 붙인다. 검증 범주6개는 외부 학습 fold로 다시 적합한다.
- 150회 LambdaRank를 고정한다. 기존 78개만 사용하는 동일 데이터 대조군도 학습한다. 학습한 Qwen/BGE의 예측을 새로운 학습 특징으로 사용하지 않는다.
- 직접 선택과 `기존 v8 확률25% + 새 재순위기 확률75%` 두 방법을 사전에 정했다. 기존 v12가 생략한 신경망 확률을 임의 복원하지 않는다. 조건을 통과하는 후보 중 직접 선택을 우선한다.
- 검증은 v12와 완전히 같은 상위20후보를 사용하며 기존 계산 생략 한글 행도 모두 처리한다. 검증 후보에 정답을 추가하지 않는다. 실제 비한글 입력은 v12 예측을 유지한다.

[사전 조건](../experiments/reverse_ranker_protocol.json), [코드·데이터 해시 및 정확성 검사](../experiments/reverse_ranker_lock.json), [학습·검증 데이터 검사](../experiments/reverse_data_inspection.json)를 저장했다.

## 구현 검사와 규모

첫 정확성 검사는 배치8·왼쪽 패딩256·출력 위치65에서 수행했다. 전체 필요 쌍의 최대 관측 길이13·합계 길이84토큰을 확인한 뒤, 성능 결과를 보기 전에 **고정 배치32·왼쪽 패딩128·출력 위치33**으로 계산 설정을 바꿨다. 관측명은 최대32토큰이며 초과 시 명시적으로 실패하고 자르지 않는다. 이전 설정의 점수는 보존만 하고 재사용하지 않는다. 새 설정도 같은 정확성 검사를 통과했다. 실제 배치1과 최대 평균0.06895 차이가 있어 배치 프로토콜을 혼용하지 않는다.

인공 이름으로 확률 직접 계산과 대조했다. 전체 forward의 shifted cross-entropy 합과 최대 차이0.00000237이었고, 반복·후보 역순·단독 후보·동반 후보와 슬롯 변경은 고정 배치에서 정확히 같았다. 이 검사 범위에서 순수 이름 쌍 캐시를 사용할 근거를 확인했다. 최종 패키지의 실제 행 독립성 검사를 대신하지는 않는다.

전체 이름 실험이 탈락한 경우에만 실행할 **단어 생략 확률 합산**도 결과 확인 전에 [별도로 등록](../experiments/reverse_kanana_partial_v1_protocol.json)했다. 전체 이름에0.5를 주고 나머지0.5를 생략 단어 수의 `exp(-n)`에 비례해 모든 연속 단어 구간에 정규화한다. 각 조건부 확률을 이 사전확률로 합산하므로 후보가 길다는 이유로 무제한 최댓값 선택의 이득을 주지 않는다. 전체 이름 점수6개에 합산 점수6개를 더하며, 대조군은 이미 고정한 전체 이름 모델이다. 추가114,470쌍을 계산했다.

fold 0·2의 학습 96,000쌍과 평가 53,020쌍은 중복 제거 후 **71,830개 이름 쌍**이다. 평가2,658행 중 실제 한글2,651행을 새로 판별하며, 이 중 기존 v12가 생략한 행은2,116개다. 나머지7행은 기존 경로를 유지한다.

## 채택 기준과 한계

두 fold testlike가 v12보다 최소+0.003이고, 가장 나쁜 fold는-0.002 이상, hard 한글과 단어 생략은-0.002 이상, clean 기존 정답 손실은1행 이하이어야 한다. 역방향 점수 추가의 효과도 같은78개 특징 대조군보다 최소+0.001이어야 한다. 통과하면 fold3 별도 변형 진단 후 전체5-fold에서+0.005·4개fold 개선 등을 확인한다.

역사적 v8 후보 검색은 전체 학습 범주 매퍼를 쓴 예외가 남아 있다. 새 범주 특징의 분리만으로 검색 단계의 예외를 없앴다고 주장하지 않는다. 검증 세트도 반복 사용한 탐색용이며 실제 Public 성능은 별도다. 현재 실제 최고는 v12 **0.9065951735**, 서버 **591초**, 제출 **9회**다.

## 전체 이름 실험 결과: 기각

아래는 **fold0·2 합산**이며 전체5-fold나 Public 점수가 아니다. [비교 결과](../experiments/reverse_kanana_v1_audit.json)

| 방법 | testlike | v12 대비 | 동일78개 특징 대조군 대비 |
|---|---:|---:|---:|
| v12 | 0.9178774610 | — | — |
| 역방향 특징 직접 선택 | 0.9039248651 | -0.0139525959 | +0.0029548533 |
| v8 25% + 새 재순위기75% | 0.9052995829 | -0.0125778781 | +0.0012641084 |

직접 선택의 clean은 유지됐지만 hard는0.866003→0.860472로 하락했다. 단어 생략 한글은0.846501→0.819413, 생략+결측은0.586907→0.521445였다. testlike 회복25행·손실70행, 두 fold 모두 하락했다. 선박 bootstrap 95% 구간은 직접 선택[-0.024867,-0.004235], 25/75결합[-0.022775,-0.003223]이다. 새 점수 자체는 동일 특징 대조군보다 좋았지만 기존 v12를 대체하기에는 부족해 두 안 모두 기각했다.

[후속 진단](../experiments/reverse_kanana_v1_diagnostics.json)에서 역방향 이름 점수만 사용하면 단어 생략 한글0.334086, 생략+결측0.302483이었다. 학습한 직접 선택에서는 역방향 특징의 분할 이득 비중이 약58%였지만, 이 수치를 인과적 효과로 해석하지 않는다. 기존 전체 그룹 strict 단일 트리도 같은 역사적 후보에서 testlike0.887033이므로 학습 그룹 수 부족만으로 회귀를 설명할 근거는 없다. 이 단일 트리 비교는 검색/학습 구성이 다른 사후 진단이며 추가 후보 선택에 쓰지 않았다.

## 생략 구간 합산 결과: 기각

10월28일104,704쌍까지 저장된 뒤 작업이 중단됐다. 10월29일 코드·프로토콜 해시가 그대로인 것을 확인하고, 남은9,766쌍만 재개해 두 fold 학습·평가를 완료했다. 전체 고유 이름 쌍은186,300개다. [비교 결과](../experiments/reverse_kanana_partial_v1_audit.json)

| 방법 | testlike | v12 대비 | 전체 이름 모델 대비 |
|---|---:|---:|---:|
| 생략 합산 직접 선택 | 0.9029925852 | -0.0148848758 | -0.0009322799 |
| v8 25% + 생략 합산75% | 0.9044937138 | -0.0133837472 | -0.0008058691 |

직접 선택의 clean은 유지됐다. 단어 생략 한글은0.796840, 생략+결측0.541761, hard 가중 점수0.855732였다. 전체 이름 모델에 비해 생략+결측은 나아졌지만 단어 생략은 더 떨어졌다. v12 대비 testlike 회복28행·손실74행으로 두 후보 모두 초기 기준에 미달했다. 직접 선택의 선박 bootstrap 95% 구간은[-0.025476,-0.005000]이다.

연속 단어 구간만 다뤘으므로 중간 단어 하나를 지운 뒤 남는 비연속 구간·철자·띄어쓰기 변형 전체를 확률로 합친 실험은 아니다. 이번 고정 프롬프트·사전확률·특징·단일 트리 구성이 기각됐으며, 모든 음역 확률 방법이 무효라는 결론은 아니다.

두 종류 재순위기의 저장·재로딩, 전체53,020후보 점수의 행 순서 변경·단독 예측,64개 그룹의 후보 순서 변경 검사를 통과했다. 추가로 실제 공식 이름96쌍에서 캐시와 새 GPU 계산·역순·3쌍 단독·중복 후보를 포함한 질의 API 점수가 정확히 같았다. 새 제출 패키지의 전체 실행 검사를 했다는 뜻은 아니다. [생략 합산 모델 검사](../experiments/reverse_kanana_partial_v1_head_checks.json), [실제 이름 쌍 검사](../experiments/reverse_kanana_partial_v1_real_pair_checks.json)

네 후보 모두 초기 조건에 미달해 별도 fold3 성능 평가·전체5-fold·최종 전체 학습·새 ZIP·대회 제출은 하지 않았다.

## 두 안 탈락 시의 후보 공동 비교 교사 진단

생략 합산 성능을 보기 전에 [소규모 교사 진단](../experiments/joint_qwen4b_probe_v1_protocol.json)도 준비했다. 기존 캐시의 Qwen3-4B-Instruct-2507을 사용하며 새 가중치 다운로드는 없다. 두 역방향 실험 모두 탈락해10월29일 실행했다.

fold1·4에서 v12가 실제 판별한 단어 생략/생략+결측 사례 중, few-shot 선박을 제외한 **서로 다른60척**을 고정 난수로30척씩 선택했다. 행 정답의 정오나 상위20 정답 포함 여부로 선별하지 않는다. 이름·공식 제원·기존 영문 복원 힌트와 후보20개를 함께 읽게 하고, 정답 레터의 마지막 토큰 확률을 계산한다. 카탈로그 순서 정방향/역방향의 확률을 고정 평균한다. 실제 선박 ID·호출부호는 입력하지 않는다.

프롬프트 최대1,310토큰·레터A~T 각각 단일 토큰을 CPU에서 확인했다. 배치1·BF16·SDPA, 최대2,048토큰으로 자르지 않는다. v12 대비 최소3척/+0.05 정확도 개선일 때만 더 큰 교사 비교로 확대한다. 작은 선별 진단이므로 공식 가중 점수나 Public 예측으로 해석하지 않는다. 증류·최종 모델은 교사 품질 확인 이후 별도 검증할 단계다.

실제 결과는 v12 **21/60(35.0%)**, 교사 **17/60(28.33%)**였다. 회복7척·손실11척, 순감4척으로 확대 기준에 미달했다. fold1은11→12척, fold4는10→5척이었다. 약71.6초에 평가했고 반복 확률이 정확히 같았으며, 허용 레터에 배정한 전체 확률의 최솟값도0.99974로 출력 형식을 따르지 않아 생긴 실패는 아니었다. [결과](../experiments/joint_qwen4b_probe_v1_result.json)

어려운 사례만 뽑은60척의 진단이며 v12 전체 성능이35%라는 뜻은 아니다. 이 고정 프롬프트·4B 모델·두 순서 평균 구성만 평가했다. 모든 후보 공동 비교 모델이 무효라는 결론으로 확대하지 않는다. 더 큰 교사 비교·증류는 실행하지 않았다.

## 결론과 다음 실험

186,300개 이름 쌍과 실제 학습·검증을 마쳤지만 이번 구성은 v12를 넘지 못했다. 역방향 점수 자체는 같은78개 특징 대조군에 추가 효과가 있었으나, 기존 지도학습 Qwen/BGE를 포함한 최종 선택을 대체할 수준은 아니었다. 현재 실제 최고 Public은 **0.9065951735**, 서버 **591초**, 제출 **9회**다. 목표0.97에는 도달하지 않았다. [결산·검사 결과](../experiments/reverse_iteration_20261029.json)

후속 우선안은 **기존 지도학습 판별기의 정보를 보존한 학습형 최종 결합**이다. 외부 학습 fold 안에서 Qwen/BGE의 내부 교차 예측을 새로 만들고, 원시 특징·점수의 그룹 내 순위/차이·불확실성·역방향 점수를 함께 넣는다. 기존5-fold 점수를 다시 나눠 쓰는 방식은 사용하지 않는다. 새 최종 선택에서는 기존25% 생략 경계가 유효하지 않으므로 생략했던 한글 행의 실제 신경망 점수도 다시 계산해야 한다. 이 후속은 아직 구현·학습하지 않았으며 개선을 보장하지 않는다.

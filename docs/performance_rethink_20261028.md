# v12 이후 성능 개선 방향 재검토

> 아래는 분석·제안 당시 기록이다. 이후 추천 방향으로 A1/A2/B/C를 실제 학습·평가했지만 모두 사전 채택 조건에 미달했다. 기존 v12를 유지한다. [최신 실행 결산](learned_alignment_20261028.md)

기준일 2026-10-28. 현재 확인된 최고 Public은 v12 **0.9065951735**, 서버 **9분 51초**다. 목표 0.97과 호출부호·train/test 동일 선박 조회 제외 조건을 유지한다. 이번에는 기존 저장 점수·학습 후보를 분석하고 관련 원 논문을 검토했다. 새로운 모델 학습·합성 질의 생성·ZIP 조립·대회 제출은 하지 않았다.

결론은 **같은 데이터의 반복 학습보다 약칭·톤수 결측을 배우는 데이터 구성과 음역 구별 근거를 바꾸는 것이 우선**이라는 것이다. 아래는 실행 전 가설이며 효과를 입증한 새 모델은 아니다.

## 1. 남은 오차가 집중된 곳

기존 v12의 5-fold 예측을 재구성해 testlike 0.9118708558과 모든 예측을 일치시켰다. 재현은 `.venv/Scripts/python.exe -m tools.analyze_v12_opportunities`, 결과는 [v12_opportunities_audit.json](../experiments/v12_opportunities_audit.json)이다. 기본 분석 학습 fold는 1·2이며 `--training-folds`로 바꿀 수 있다.

### 시나리오별 오차 예산

| 시나리오 | 오답/행 수 | 전체 가중 오차에서 차지하는 비중 |
|---|---:|---:|
| 원본 한글 | 3 / 1,191 | 0.9% |
| 톤수 결측 | 20 / 1,191 | 1.9% |
| 단어 생략 | 212 / 1,191 | 32.5% |
| 단어 생략+톤수 결측 | 506 / 1,191 | **64.1%** |
| 비한글 원본 | 20 / 11,031 | 0.6% |

이는 원본 44% / 결측 14% / 생략 23% / 둘 다 19%를 쓰는 **인공 로컬 지표의 오차 구성**이다. 실제 Public의 구성비를 알아낸 것이 아니다. 생략+결측 506개 오답 중 494개는 실제로 이름의 단어가 줄어든 행이다.

### 후보 단계별 오차 예산

| 오류 단계 | 로컬 점수 손실 | 전체 가중 오차 비중 |
|---|---:|---:|
| 정답이 검색 후보 전체에 없음 | 0.003726 | 4.2% |
| 검색됐지만 기존 모델 상위 20개 밖 | 0.006700 | 7.6% |
| 상위 20개 안이나 승자 보존 경계로 신경망 생략 | 0.011032 | 12.5% |
| 상위 20개를 실제 판별했으나 오선택 | **0.065903** | **74.8%** |
| 한글이 사라진 입력의 기존 경로 및 비한글 오류 | 0.000767 | 0.9% |

즉, 후보 검색 확대만으로 남은 오차 대부분을 해결할 수 없다. 생략+결측 506개 오답 중 397개는 정답이 상위 20개에 있었고 실제 판별까지 했지만 틀렸다. 검색 후보 전체에서 빠진 것은 28개, 20위 밖은 51개, 생략 경계는 28개, 실제 비한글 경로는 2개다.

정답을 아는 선택기의 값도 구분한다.

- 저장된 기준 모델·각 신경망·각 25% 결합의 **1등 중 정답을 골라주는 선택기**: 0.930755. 생략된 신경망 점수는 없는 상태를 유지한 오라클이며, 임의의 새 재순위 모델이나 모든 점수 결합의 상한은 아니다.
- v12 상위 2개 중 정답 선택: 0.936339, 상위 5개 0.965449, 상위 10개 0.981318, 상위 20개 0.989030. 두 후보만 비교하는 방식으로 0.97에 도달한다는 근거는 없다.
- 생략+결측만 100% 맞히고 다른 정확도를 고정해도 로컬 값은 0.968376이다. 이 구성에서는 다른 약칭도 함께 개선해야 0.97에 이른다. 실제 Public 예측값은 아니다.

## 2. 새로 확인한 학습 구성의 빈틈

| 항목 | fold 1 | fold 2 |
|---|---:|---:|
| 실제 사용 그룹 | 2,400 | 2,400 |
| 양성 학습 대상 선박 | 304척 | 313척 |
| 추가 철자 변화 없는 정확한 단어 생략 | 212 | 211 |
| 위 단어 생략+GT·IGT 모두 결측 | **88 (3.67%)** | **87 (3.63%)** |
| 정확한 단어 생략 외의 이름 변화 | 1,226 | 1,257 |
| 검색 후보에 정답이 없어 제외된 학습 행 | **135 / 4,815** | **127 / 4,905** |

관련 노이즈가 학습에 전혀 없다는 뜻은 아니다. 단어 생략에 철자 변화까지 겹친 행도 학습된다. 다만 현재 평가의 핵심인 **추가 철자 변화 없는 약칭+결측**의 직접 학습 비중은 낮다. 검증에서 실제 단어 생략+결측이 차지하는 testlike 혼합 질량은 약 14.0%다. 학습 비율과 평가 혼합 질량의 비교는 진단이며 실제 test 분포의 증거는 아니다.

전체 그룹으로 늘린 이전 실험도 양성 선박 종류나 노이즈 생성법은 거의 그대로였다. 그 실패가 새로운 이름 패턴·다른 증강 구성이 무효라는 뜻은 아니다. 반대로 데이터 구성 변경이 개선을 낼지도 아직 모른다.

## 3. 우선순위 1 — 같은 예산으로 학습 사례를 바꾸기

첫 실험은 모델·입력·학습률·2,400개 그룹·1 epoch·결합 비율을 유지한다.

**A1. 깨끗한 약칭+결측 사례를 늘린다.** 학습 fold 원본에서 첫/마지막/임의 단어를 실제로 지우고 GT·IGT를 가린 사례를 새로 만든다. 이 유형의 노출을 15~20%로 늘리는 안을 시험한다. 같은 88행을 그대로 반복하는 방법 대신 남은 단어·생략 위치·관측 메타데이터가 다른 실제 학습 변형을 확보한다. 나머지 사례는 기존 학습 분포를 유지해 원본과 hard의 회귀를 감시한다. 이 비율을 실제 test 구성비로 주장하지 않는다.

**A2. 검색 실패 행을 학습에서 버리지 않는 안을 따로 비교한다.** 학습에서만 공식 정답 카탈로그 행을 양성으로 붙이고, 원래 검색된 혼동 후보는 음성으로 유지한다. 검증·추론에는 정답을 강제로 넣지 않는다. 이는 어려운 질의의 감독 신호를 보완하는 방법이며 실제 평가의 검색 누락을 직접 해결하는 것은 아니다.

A1·A2는 별도 비교 후 결합한다. 처음부터 입력·가중치·후보 수를 함께 바꾸지 않는다. 긍정 ID는 학습에만 쓰고 모델 입력에는 넣지 않는다.

## 4. 우선순위 2 — 공식 카탈로그로 새 이름 패턴을 공급하기

이미 본 304척의 변형을 더 만드는 방법과 구분한다. **공식 카탈로그에서 추가 선박명 약 3,000개를 고른 작은 실험**을 제안한다.

1. 외부 검증 선박은 합성 학습 대상에서 제외한다. 선택에는 학습 fold와 공식 카탈로그만 사용하고, 검증 오답 선박을 합성 학습 대상으로 고르지 않는다.
2. 기존 공개 범용 Kanana 가중치로 카탈로그 영문명을 한글 음역 2~3가지로 바꾼다. 새로운 선박명·제원·등록 이력 같은 사실을 생성하거나 외부 선박 자료를 붙이지 않는다. 공식 train에서 얻은 예시도 학습 fold에서만 가져온다.
3. **온전한 이름 단계에서** 숫자 보존·중복·음역 품질을 점검한다. 필요하면 이름만 쓰는 왕복 검색으로 낮은 품질을 거른다. 약칭으로 만든 뒤 원래 전체 이름을 복원하지 못한다고 버리면 어려운 사례를 다시 제외하게 되므로, 품질 확인 후에 단어 생략·결측을 적용한다.
4. 실제 학습 사례와 합성 사례를 섞되 총 업데이트 수를 고정한다. 선박 ID·호출부호는 입력에서 제외하고, 실전 예측에 합성 별칭→선박 조회표를 두지 않는다.
5. 평가는 생성된 이름이 아닌 **실제 원본 한글 기록을 가진 미학습 선박**으로 한다. 합성 데이터에서 잘 맞히는 것만으로 채택하지 않는다.

문서에서 질의를 생성해 검색 학습 데이터를 확장하는 일반적 근거는 [InPars](https://arxiv.org/abs/2202.05144)에 있다. 여기의 선박명 적용은 새 가설이며 그 논문이 본 대회의 개선을 보장하지 않는다. 데이터 사용 범위는 [공식 규칙](https://dacon.io/competitions/official/236771/overview/rules)의 train·catalog와 공개 범용 가중치 조건을 유지한다.

합성 약칭이 여러 자매선과 똑같이 양립하는 경우도 생긴다. 이런 사례에 보이지 않는 접미사를 맞히도록 강제하지 않으며, 이름 호환성 학습과 개별 선박 선택의 불확실성을 구분해야 한다.

## 5. 우선순위 3 — 모음을 보존하는 독립 발음 정렬 점수

현재 규칙 키는 한글 중성과 영어 모음을 버린다. 원문을 받는 신경망까지 모음 정보가 전부 없어진 것은 아니지만, 검색 키·규칙 정렬 층에서 구별 근거가 약해진다.

실제 저장 예측·음역에서 확인한 예시는 다음과 같다. [상세](../experiments/v12_phonetic_examples.json)

| 입력 | 정답 | v12 오답 | 점검할 점 |
|---|---|---|---|
| 루니 | Luni | SS Luna | Luni가 이미 세 번째 음역 후보에 있는데도 선택 실패 |
| 가스오너 | Gas Honour | Gas One | 음역은 Gasoner/Gasooner 등, 발음과 띄어쓰기 대응 필요 |
| 펭슈하이 | Feng Xiu Hai | Feng Shou Hai | 한글 음절·중국어 로마자 모음 대응이 구별 단서 |

제안은 한글 자모/음절과 영문 문자·짧은 문자열 사이의 **학습된 대응 확률**로 후보 이름의 관측된 부분을 정렬하는 작은 모델이다. 생략된 단어는 건너뛰고, 입력에 없는 단어를 생성하도록 요구하지 않는다. 기존의 자음 키·영문 빔 Levenshtein/IDF 특징 28개를 다시 붙이는 방법과 다르다.

초기에는 공식 train의 한글–카탈로그 이름 쌍만 사용한다. 작동하면 위의 카탈로그 기반 합성 음역으로 새 철자 패턴을 보완한다. 학습된 이름 호환 점수를 기존 재순위의 새 입력으로 평가하며, 입력과 제원으로 구별할 수 없는 자매선을 이것만으로 해결한다고 주장하지 않는다.

통계적 음역 대응·음역/비음역 분리를 학습하는 근거는 [Sajjad et al.의 음역 모델](https://aclanthology.org/J17-2003/)에 있다. [ByT5](https://aclanthology.org/2022.tacl-1.17/)도 철자·발음과 잡음에 민감한 작업에서 문자/바이트 표현을 검토할 근거지만, 새 가중치 다운로드·교체는 작은 정렬 점수의 유효성 확인 후에 판단한다.

## 6. 보조 실험과 낮춘 우선순위

**학습된 점수 결합:** 기본 순위·Qwen/BGE 점수·이름 정렬 점수·메타데이터 신뢰도를 작은 재순위기에 함께 넣는다. GT 결측 여부나 선종·국적 충돌에 따라 어떤 근거를 믿을지 학습하므로 전체 비중을 40%로 고정한 실패와는 다른 가설이다. 학습용 신경망 점수도 해당 행을 학습하지 않은 모델에서 얻어야 한다. 외부 검증 fold를 완전히 제외한 내부 분할이 필요하며, 같은 학습 행의 예측을 그대로 학습하면 과적합 위험이 크다는 점은 [공식 stacking 문서](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.StackingClassifier.html)와도 일치한다. 계산량이 늘어 1순위로 두지 않는다.

**선종·국적의 조건부 신뢰도:** 생략+결측 오답 506개 중 정답/오답의 카탈로그 선종·국적이 모두 같은 것은 274개, 적어도 하나 다른 것은 232개다. 원본 입력의 범주가 틀릴 수 있어 단순한 국적·선종 일치 필터는 위험하다. 필요하면 학습 fold의 원시 범주·연도·다른 제원 조건으로 신뢰도를 추정하는 별도 보정안을 평가한다. 추가 특징 실험에 원시 `arrival_year`는 이미 있었으므로 단순 연도 추가를 새 방법처럼 반복하지 않는다. [사례·집계](../experiments/v12_metadata_opportunity.json)

**상위 50개 확대:** 상위 20개 밖의 정답을 완벽하게 회복해도 현재 로컬 손실 기준 최대 +0.006700이다. 신경망을 믿을 새로운 근거가 생긴 뒤 결측·고모호성 행에서만 검토한다. 실제로 새 후보를 점수화하고 계산 생략 경계·행 독립성·시간을 다시 검사해야 하며, 정답 선택 오라클을 실제 성능으로 쓰지 않는다.

**반복하지 않을 첫 시도:** 같은 데이터의 그룹 수·epoch·시드·전역 비중 탐색, 무학습 Kanana의 후보 직접 선택, 이미 기각한 영문 빔/IDF 특징의 단순 재추가, 원래와 같은 Kanana 음역 파인튜닝이다. 각각 이전 실패의 범위만 인정하며 모든 변형이 불가능하다고 단정하지 않는다. Ditto의 쌍 분류나 ColBERT의 토큰 상호작용 같은 연구를 검토했지만, 논문 이름만 바꿔 기존 입력·감독 신호를 반복하는 방안은 우선하지 않는다.

## 7. 다음 실험의 제안 순서와 측정 기준

아래는 **제안**이며 이번에 실행하거나 통과한 조건이 아니다.

1. A1을 같은 2,400개 그룹·1 epoch·기존 결합에서 먼저 비교한다. 새 증강 생성 시드와 표본을 학습 전에 고정하고, 학습/검증 선박 분리를 확인한다. A2는 독립 비교한다.
2. 기준 모델은 v12다. fold 0·2를 먼저 비교하고 testlike +0.002 이상, hard 한글·톤수가 남은 약칭의 하락 최대 0.002, 원본 정답 손실 최대 1행을 요구하는 안을 제안한다.

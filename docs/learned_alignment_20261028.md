기준 2026-10-28. 추천 방향에 따라 실제 학습·평가한 **네 후보 모두 사전 채택 조건에 미달했다**. 새 개선 모델이나 ZIP은 없고, 실제 최고는 **v12 Public 0.9065951735 / 서버 9분 51초 / 제출 9회**다. 0.97은 달성하지 못했다.

## C: 무엇을 학습했는가

`src/learned_alignment.py`에서 한글 초성·중성·종성을 모음을 유지한 철자열로 옮기고, 영문 원문 문자와의 대응 비용을 학습한다. 기존 자음 키는 그대로 유지한다. 작은 구현은 문자 교체·삽입·삭제의 Viterbi 정렬과 카운트 기반 MAP 갱신 4회이며, 관측한 한글 전체를 소비하되 영문 이름의 앞뒤 완전한 단어는 생략할 수 있다. 추론 시 정답 ID나 다른 행을 참조하지 않는다.

대응 확률을 학습한다는 연구 근거는 [Sajjad 등의 통계적 음역 모델](https://aclanthology.org/J17-2003/)이다. 여기 구현은 그 논문의 EM 혼합 모델을 재현한 것이 아니며, 이 작은 문자 채널의 본 대회 유효성은 별도로 확인했다.

fold 0에서는 실제 학습 선박 이름 쌍 **308개**, fold 2에서는 **314개**만 사용했다. 양성의 공식 선박명을 연결할 때만 ID를 사용하며, 검증 선박과 중복은 0척이다. 합성 카탈로그 음역은 이 실험에 넣지 않았다. 이름 쌍을 매핑한 조회표를 추론에 쓰지 않고 학습된 37×37 비용 행렬만 사용한다.

[학습 전 프로토콜](../experiments/learned_alignment_protocol.json)에 **v8 75% + 기존 Qwen 10% + 기존 BGE 10% + 정렬 5%**를 고정했다. 정렬 비용을 관측 길이로 나눈 값의 -10배를 후보 softmax 점수로 사용했다. 실제 비한글 행·기존 계산 생략 경로는 v12 기본 예측을 유지했다. 메타데이터를 보고 사후에 적용 행을 고르거나 새 가중치를 탐색하지 않았다.

## 해석과 남은 방향

현재 네 구성에서 개선을 입증하지 못했다. 학습 비중 변경·양성 복원·새 이름 노출·독립 발음 점수 전체가 불가능하다는 결론은 아니다. A1과 C는 약칭 조건 사이의 회복·손실이 달라 하나의 전체 비중으로 안정적인 개선을 얻기 어려웠다.

후속은 같은 검증에서 비중을 반복 조정하기보다, 문자 한 개 대응을 여러 문자·음절 대응으로 확장하거나 합성 음역의 모음·약어 품질을 더 검증하는 쪽이 타당하다. 조건부 결합을 학습한다면 학습용 신경망 점수도 외부 검증 선박을 제외한 내부 분할에서 만들어야 한다. 이 후속 방법은 아직 구현·검증하지 않았다.

모든 CV는 반복 사용한 탐색용 합성 검증이고 과거 v8 평가 후보 매퍼 예외가 남는다. fold4의 별도 진단은 A1에서 이미 관찰했으며, 이번 B·C는 초기 조건에 미달해 fold3의 7종 진단을 사용하지 않았다. `call_sign`·동일 선박 조회 제외 방침은 유지한다.

# 순위 판별 전용 Qwen3-Reranker-4B의 고정48척 진단

2026-10-30. **공개4B전용모델을실제로내려받아실행했으나v12 17/48정답에서15/48로하락해확대하지않았다.** 새학습·양자화·제출용모델·ZIP·실제제출은없다. 실제최고Public은v12 **0.9065951735**다.

## 무엇을 바꿨는가

앞선 [입력 표현 두 안](explicit_input_20261030.md)도기각된뒤, 더큰전용재순위모델의사전학습신호를작게검증했다. 앞서후보공동판정을시험한Qwen3-4B대화모델과구분되는 **Qwen3-Reranker-4B**다. 이번에는후보목록을공동으로읽게하지않고, 질의–후보쌍에대한yes/no로짓차를점수화했다.

[공식모델카드](https://huggingface.co/Qwen/Qwen3-Reranker-4B)의Apache-2.0을확인하고고정revision `22e683669bc0f0bd69640a1354a6d0aebcfeede5`를받았다. 범용가중치·토크나이저·설정·모델설명만받았으며외부선박자료·정답표·추가데이터셋은없다. stockTransformers의Qwen3클래스를사용하고`trust_remote_code=False`다.

두가중치파일은합계 **8,043,614,960바이트**다. 다운로드·해시측정139.7초였으며각파일의SHA256을저장하고모델실행전에다시확인했다. 모델은`D:/KSH/hf_models/Qwen__Qwen3-Reranker-4B`에보존한다. 기존모델과ZIP을덮어쓰지않았다.

## 입력과 수치 검사

기존v11의evidence지시문·JSON기록·질의에서만생성된최대4개음역을사용한다. 모델입력에는이름·GT/IGT·선종·국적만있고ID·호출부호는없다. 공식카탈로그의후보한개씩현재기록과비교하며실제선박사실을생성하지않는다.

BF16·SDPA·TF32비활성, 고정batch4/길이256·왼쪽패딩·마스크누적position을쓴다. 마지막batch는같은쌍으로채워서모양을유지하며조용한잘림은없다. 정확한순서/단독수치일치가안되면태스크정답을보기전에batch1로만재시도하도록고정했다. 실제실행은batch4로검사를통과했다.

공식fold3기록과공식카탈로그의비진단쌍9개로수치검사를먼저했다. 정답률을계산하지않는검사다. 이후실제진단질의3개에서도역순·단독·후보순서의점수가완전히같음을확인했다.

## 미리 고정한 사례와 확대 조건

[프로토콜](../experiments/dedicated_reranker4b_v1_probe_protocol.json)은새모델의진단쌍점수·정답률을보기전에저장했다. 그전에수행한것은수치검사와입력길이확인이다.

- 기존[Kanana전방확률진단](forward_name_probe_20261029.md)의 **동일48척**을그대로사용한다. 다른사례를뽑거나기존오답만고르지않았다.
- 기존fold0·2의약칭/약칭+결측, 실제v12의30%잔차결정영역, 원래상위20에정답이있는고정사례다. 기존few-shot선박제외와선박당한사례조건을유지한다.
- 후보는 **실제v12상위20분포70% + 새전용reranker확률30%** 하나다. 온도1·지시문·가중치를결과에맞춰탐색하지않는다.
- 확대조건은v12대비정답순증3개이상·기존정답손실1개이하·정확한수치검사통과다.

이는이미다른실험에사용한어려운조건부진단이며미관찰Public평가가아니다. 모델가용성과작은진단의개선을전체점수로옮기지않는다.

## 배포와 현재 상태

개선조건에미달해양자화·전체두fold·별도변형·전체5-fold·제출용학습·새ZIP으로확대하지않았다. bitsandbytes도설치하지않아기존환경의의존성을바꾸지않았다.

원시BF16가중치8.04GB와현재ZIP6.98GB를기준으로하면추가탑재에크기부담이있어, 통과시별도의4bit변환·점수·행독립·시간·실제ZIP크기검증을거치도록계획했다. 이것은포장전예산검토이며새ZIP을만들어압축후크기를측정한결과는아니다. [양자화공식설치문서](https://huggingface.co/docs/bitsandbytes/main/en/installation)의하드웨어지원확인은실제양자화검증과구분한다.

이번실패는현재지시문·입력·온도·30%결합의작은고정진단에한정된다. 모든4B모델이나추가학습의불가능성으로일반화하지않는다. 현재목표0.97달성경로는확보하지못했으며실제최고Public·제출횟수는유지한다. [종합 결산](../experiments/representation_iteration_20261030.json)

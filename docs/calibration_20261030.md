# 기존 전문가 점수의 저차원 보정 실험

2026-10-30. **조건부6계수·공통3계수 두 후보 모두 실제 적합·검증 후 기각했다.** 실제 최고는 v12 Public **0.9065951735**, 서버9분51초, 제출9회다. 이 실험에서 새 신경망은 학습하지 않았고 제출용 모델·ZIP·실제 제출도 없다.

## 가설과 학습 자료

기존 [내부 교차 예측 결합](nested_combiner_20261029.md)은105개 이상의 특징으로 새 순위 모델을 학습했다. 이번에는 실제v12를 기준점으로 두고 기존 기본 모델·Qwen·BGE의 분포만으로3개 또는6개 계수를 학습했다. 복잡한 재순위기 대신 강한 정규화가 있는 작은 보정으로 최종 선택을 개선할 수 있는지 비교한 것이다.

모델의 확신과 정확도를 구분하는 근거로 [Guo 등의 calibration 논문, ICML2017](https://proceedings.mlr.press/v70/guo17a.html)을 확인했다. 이번 구현은 단일 온도로 순위를 보존하는 temperature scaling을 그대로 재현한 것이 아니라, 여러 전문가의 로그 오즈를 결합해 순위도 바꿀 수 있는 별도 가설이다. 논문이 본 대회의 정확도 개선을 보장하지는 않는다.

학습에는 과거 별도로 만든 내부 선박 검증 Qwen/BGE 점수를 재사용했다. 각 전문가·검색·매퍼가 해당 내부 검증 선박을 보지 않았으며 외부fold0·2의 선박도 모두 제외돼 있다. 기존 전체5-fold 예측을 단순 재분할해서 사용하지 않았다. 이는 [공식 stacking 설명](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.StackingClassifier.html)의 외부 예측을 이용한 최종 모델 적합 원칙을 따른다.

내부 기본 모델의 상위2확률 차이가1/3 이하인 불확실 그룹만 남겼다. 각 선박의 시나리오 가중치를 정규화해 학습 선박마다 총 가중치1을 부여했다. 이름·ID·호출부호는 보정 특징에 없으며, GT 또는IGT의 양수 값 존재 여부만 조건부 계수 선택에 사용한다.

| 자료 | 외부fold0 | 외부fold2 |
|---|---:|---:|
| 보정 학습 그룹 | 1,187 | 1,158 |
| 보정 학습 선박 | 245 | 244 |
| GT·IGT 모두 없는 그룹 | 667 | 646 |
| 학습/외부 검증 선박 중복 | 0 | 0 |

## 고정한 두 후보

각 후보의 점수는 `log(v12 확률) + Σ β × clip(log(전문가 확률) − log(v12 확률), −8, 8)`이다.

- `pooled3`: 기본 모델·Qwen·BGE에 대해 공통 계수3개.
- `conditional6`: 톤수 존재/모두 결측 두 조건에 계수3개씩.
- 초기 계수0, 각 계수 범위−0.5~0.5, L2=0.05, 후보 교차엔트로피와 정규화항을 L-BFGS-B로 최소화한다. 외부 점수로 계수를 탐색하지 않는다.
- 실제v12가 신경망을 계산하던 한글 행에만 적용한다. 기존 생략 행·비한글 행·후보 집합은 보존하므로 추가 신경망 호출은 없다.

두 후보와 우선순위, 전체 개선+0.003·각fold−0.002·hard/단어생략−0.002·원본 손실1행 이하 등을 [적합 전 프로토콜](../experiments/expert_calibration_v1_protocol.json)에 고정했다. 대조군은 보정 계수0인 실제v12다.

기울기와 유한 차분의 최대 오차는3.77e−10이었다. 보정 계수0의 승자, 후보 순서·점 단위 산술·ID 입력 무시를 검사했다. 두fold×두구성의 총4개 보정 모델을 적합했고 모두 수렴했다.

## 추가로 확인한 사실

정답이 상위20에 있고 기존 신경망이 활성화된 testlike344행에서 가중 평균 NLL은v12 1.745679→조건부1.671635/공통1.656722로 감소했다. 그런데 최종 정답률은 하락했다. **일부 확률 손실의 개선과1등 정확도 개선은 같은 목표가 아니다.** 이 NLL은 특정 부분집합의 값이며 전체 모집단의 손실로 읽지 않는다.

내부 학습은 절반 자료의 단일 기본 모델·신경망, 외부 비교는 전체 외부 학습 자료의v8 앙상블·신경망을 쓴다. 이런 분포 차이도 해석 한계지만 이번 하락의 유일한 원인으로 확인한 것은 아니다.

결과 확인 후 정답을 쓰는 별도 진단으로, 실제v12의 기존 계산 범위에서 전문가의 후보를 완벽하게 선택하는 가상 값을 계산했다.

| 정답을 아는 가상 선택 범위 | 같은 두fold testlike |
|---|---:|
| v12 승자 또는 기본/Qwen/BGE의1등 중 선택 | 0.934026 |
| v12 승자 또는 각 전문가 상위3개 중 선택 | 0.964191 |
| v12 승자 또는 각 전문가 상위5개 중 선택 | 0.972060 |

이는 달성 점수·Public 예측이 아니다. 전문가1등만 바꿔 고르는 정책과 더 넓은 후보를 구별하는 학습을 구분하는 진단이다. 기존 생략 행은 그대로 두었고, 다른 재순위 방식 전체의 상한을 주장하지 않는다. [NLL·가상 선택 진단](../experiments/expert_calibration_v1_transfer.json)

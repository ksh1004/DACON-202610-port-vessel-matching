# BGE 학습 후보8개와20개 비교

2026-10-30. **네 모델 학습·점수 비교·저장 모델 검사를 완료했지만 초기 조건 미달로 기각했다.** 같은fold1·4의testlike는v12 **0.9087787707**,20후보 학습 **0.9067134242**,8후보 대조군 **0.9070876816**이었다. 실제 최고는v12 Public0.9065951735·서버9분51초·제출9회로 유지한다. [전체 결산](../experiments/improvement_iteration_20261030.json)

## 목적

[작은 보정기](calibration_20261030.md)도 v12를 개선하지 못했다. 기존 전문가의1등만 바꿔 고르는 방식과, 그 아래에 남은 후보를 구별하는 학습은 별도로 검증해야 한다.

현재 BGE는 질의당8개 후보의 교차엔트로피로 학습하고 추론에서는20개 후보를 비교했다. 이번 실험은 같은 질의에서 학습 후보를20개로 넓혀 추론 후보 수에 맞춘다. 기존8개 학습도 이미 목록 내 교차엔트로피였으므로 listwise loss의 최초 도입이라고 주장하지 않는다. 후보 간 교차 attention을 새로 도입한 모델도 아니다.

[RankT5, SIGIR2023](https://arxiv.org/abs/2210.10634)는 직접적인 순위 손실로 재순위기를 학습하는 연구다. 여기서는T5나논문모델을 재현하지 않고 기존 BGE의 학습 그룹 크기를 통제해 비교한다. 논문의 결과가 이 대회에서20개가8개보다 낫다는 근거는 아니다.

## 준비한 자료

기존seed42로 고른 학습 그룹 중 앞1,200개를 두 조건에서 동일하게 사용한다. 원래 정답1개·학습 전용LGB 음성5개·문자 혼동 음성2개를 보존한 뒤, 중복되지 않는 학습 전용LGB 상위 후보12개를 추가한다.

| 자료 | fold1 | fold4 |
|---|---:|---:|
| 학습 질의 그룹 | 1,200 | 1,200 |
| 학습 선박 | 286 | 289 |
| 8개 대조군의 쌍 수 | 9,600 | 9,600 |
| 20개 후보 모델의 쌍 수 | 24,000 | 24,000 |
| 학습/검증 선박 중복 | 0 | 0 |
| 256토큰 상한에 닿은 학습 쌍 | 0 | 0 |

20개 그룹의 앞8개 토큰 입력이 원래8개 그룹과 모두 같고, 후보 중복0·양성 위치0을 확인했다. ID·호출부호는 공식 정답 연결·선박 분리에만 쓰며 신경망 입력에는 없다. 이름·음역·발음 키·제원 입력 형식은 기존과 같다.

## 고정한 학습·비교

두 조건 모두 공개 원본BGE-reranker-v2-m3에서 시작한다. 같은 시드42·LoRA8/alpha16/dropout0.05·학습률1e−4·AdamW·weight_decay0.01·gradient clip1을 쓴다. microbatch 질의1개·누적2개로 유효batch2,1epoch600업데이트다.

두 조건의 질의·초기 가중치·업데이트 수를 맞춘다. 후보20개는 후보8개보다2.5배 많은 쌍을 보므로 계산량까지 같은 비교는 아니다. 이 차이는 실험 처치의 일부다.200업데이트마다 어댑터·옵티마이저·난수 상태를 두 슬롯에 번갈아 저장한다.

추론은v8 75%+기존Qwen12.5%+새BGE12.5%로 고정하고 기존20후보·신경망 생략 경계를 유지한다. 새20후보 학습 모델이 후보이며, 같은1,200질의의8후보 학습 모델은 대조군이다. v12와 대조군을 모두 넘어야 한다.

[학습 전 프로토콜](../experiments/encoder_list20_v1_protocol.json)에 다음 확대 조건을 고정했다.

- 초기fold1·4: v12 대비testlike+0.003, 최악fold−0.002 이상, hard/단어생략 한글−0.002 이상, 원본 정답 손실1행 이하, 새8후보 대조군 대비+0.001.
- 통과하면fold3의 별도 변형을 학습 전용 검색·few-shot 선박 제외로 평가하고, 평균 하락−0.002 이내를 요구한다.
- 이후전체5-fold: +0.005·4개fold 개선·hard한글−0.001/단어생략−0.002/OOF−0.0006 이상·대조군 대비+0.001.

모두 통과한 뒤에만 제출용 전체 학습·패키지·실제 행 독립/시간 검사로 확대한다. 이 단계의 BGE12.5% 변경만으로 목표0.97 달성을 입증하는 것은 아니다. 반복 사용한 합성CV와 기존 기준 검색 매퍼의 예외도 남아 있다.

## 실제 학습과 초기 결과

두fold×두조건의4개 모델이 모두600업데이트, 합계2,400업데이트를 완료했다. 손실·기울기는 모두 유한했고 네 모델의 초기 학습 파라미터SHA256이 같았다. 체크포인트 재개 없이 각각 공개 원본에서 학습했다.

| 학습 | 처리한 쌍 수 | 업데이트 | 학습·저장 구간 시간 |
|---|---:|---:|---:|
| fold1,8후보 대조군 | 9,600 | 600 | 133.4초 |
| fold1,20후보 모델 | 24,000 | 600 | 281.3초 |
| fold4,8후보 대조군 | 9,600 | 600 | 125.9초 |
| fold4,20후보 모델 | 24,000 | 600 | 280.9초 |

시간은 각 학습·저장 구간의 로컬 측정이며 전체 실행·평가 시간이나 서버 추론 시간은 아니다. 쌍 수는 각 모델의 처리 수이며 중복을 제거한 독립 표본 수가 아니다.

| 같은fold1·4 | testlike | hard 한글 | 단어 생략 한글 | 생략+결측 한글 |
|---|---:|---:|---:|---:|
| v12 | **0.908779** | **0.848515** | **0.819802** | **0.566337** |
| 20후보 학습 | 0.906713 | 0.847525 | 0.811881 | 0.560396 |
| 8후보 대조군 | 0.907088 | **0.848515** | 0.815842 | 0.558416 |

새 모델은v12 대비−0.0020653465, 대조군 대비−0.0003742574였다. fold별 변화는−0.0018728070/−0.0022238267, 선박bootstrap95%는[−0.004284,−0.000249]다. 변형1행 회복·8행 손실, hard1행 회복·2행 손실이며 원본 정답은 유지했다. 전체·최악fold·단어생략·대조군 기준에 미달해 선택null을 잠갔다. [비교 결과](../experiments/encoder_list20_v1_audit.json), [선택](../experiments/encoder_list20_v1_selection.json)

후보 수만 넓힌 이 고정 구성은 새 정보나 일반화 개선을 만들지 못했다. 이를 모든 후보 확대·어려운 음성 학습의 불가능성으로 일반화하지 않는다. 실패 후 그룹 수·혼합 비중·epoch·후보 수를 재탐색하지 않았다.

## 실행·보존 검사와 기록

학습·점수 로그는 [encoder_list20_v1_run.log](../experiments/encoder_list20_v1_run.log)다. 저장한4개 모델을 다시 읽어 각fold의실제질의3개씩, 두모델폭을합쳐12개 모델·질의 조합에서 저장점수·행역순/부분집합/단독·후보역순의 완전일치를 확인했다. ID·호출부호를 바꾸어도 토큰은 같았다. 이는 고정 후보와 새BGE 모델의 검사이며 새 제출ZIP 전체 실행 검사는 아니다. 독립 검사 프로세스의 반환코드는0이고 결과는PASS다. [실행 검사](../experiments/encoder_list20_v1_runtime_checks.json)

두조건의초기학습파라미터 해시일치,8개체크포인트슬롯의옵티마이저·난수상태CPU읽기와유한값을확인했다. 실제GPU중단·재개후전체재학습을한검사는아니다.

공용 점수 저장기가 과거8후보 준비 자료의 `experiment`와 `training_token_groups_exactly_legacy` 설명을 상속한 부분은 종합 결산에 현재 실험명·폭·1,200그룹·원래8개토큰접두보존으로 명시했다. 과거2,400그룹 전체를 재생한 것은 아니다. 원시 기록·실제토큰·점수·모델·채택판단은 바꾸지 않았다.

학습 실행을 감싼PowerShell은fast-tokenizer의pad안내를`NativeCommandError`로기록했고실행도구는반환코드1을보고했다. Python반환코드를별도로수집하지않았으므로이를0으로보고하지않는다. 모든학습·점수·선택파일은완성됐고Python traceback은없었으며, 이후독립저장모델검사와최종결산은각각반환코드0으로통과했다. 학습을중복실행하지않았다.

등록입력·소스44개와별도보정기38개, 기존v12 소스13개·ZIP전체SHA256·이전연구스냅샷보존을확인했다. 실제제출·제출용최종모델·새ZIP은없다. [종합 결산](../experiments/improvement_iteration_20261030.json)

```powershell
.venv/Scripts/python.exe -m tools.list20_experiment --register
.venv/Scripts/python.exe -m tools.list20_experiment
.venv/Scripts/python.exe -m tools.check_list20
```

학습·점수·선택은 완료됐다. 같은 실패 구성을 다시 실행하지 않는다. 초기 조건 미달로 별도fold3·전체5-fold·제출용 최종 전체 학습·새ZIP·실제제출로 확대하지 않았다.

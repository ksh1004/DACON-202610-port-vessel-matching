# 조건부 제원 밀도비 실험

2026-10-29. **실제 학습·평가했지만 v12를 개선하지 못해 기각했다.** 같은 fold1·4의 testlike는 v12 **0.9087787707**, 새 후보 **0.9063114440**이다. 실제 최고 Public은 **0.9065951735**, 서버9분51초, 제출9회로 유지한다. 목표0.97은 미달이다.

## 가설과 기존 방식의 차이

이름 모델을 추가하는 대신, 공식 학습 기록의 입항연도·국적·선종·크기를 후보 제원과 함께 학습했다. 기존 v8도 국적·선종별 주변 사전통계를 쓰므로, 이번 비교는 그 통계의 단순 추가가 아니다. 실제 기록의 정답 제원 쌍과 공식 카탈로그에서 무작위로 뽑은 배경 쌍을 구별하는 작은 분류기를 학습한다.

관측 쌍과 배경 쌍을 분류해 밀도비를 추정한다는 아이디어는 [Gutmann·Hyvärinen, JMLR2012](https://www.jmlr.org/papers/v13/gutmann12a.html)를 참고했다. 여기서는 별도 정규화 상수를 학습하는 논문의 NCE 모델을 그대로 재현한 것이 아니라, 분류기의 로그 오즈를 속성 연관 점수로 사용하는 응용이다. 논문이 이 대회의 개선을 입증하지는 않는다.

국적·선종의 직접 대응과 크기 선호가 이미 기본 모델에 있을 수 있으므로, 후보 속성만 쓰는 분류기의 점수를 뺐다. 해석은 학습 시 정의한 선박 균등 모집단에서의 `log P(후보 속성 | 질의 속성) / P(후보 속성)` 근사이며, 보정된 선박 정답 확률은 아니다.

## 입력과 선박 분리

- 질의: 국적·선종, 3년 단위 입항연도 구간, GT 또는 IGT의 넓은 크기 구간.
- 후보: 국적·선종·단위, GT·DWT·size 구간, DWT/GT 구간.
- 이름·전체 이름 토큰·호출부호·ID·정확한 톤수는 특징에서 제외했다. 톤수 구간 경계는100/300/1,000/3,000/10,000/30,000/100,000/300,000으로 고정했다.
- 범주나 구간은 서로 다른 학습 선박10척 이상에서 지원될 때만 개별 코드로 남기며 나머지는 공통 미지 값으로 묶었다. 이는 특징 값의 최소 지원이며 모든 교차 조합이나 모든 트리 잎이10척을 보장한다는 뜻은 아니다.

외부 검증 선박을 통째로 제외한 공식 원본 한글·영문 기록을 쓴다. 같은 선박의 같은 제원 맥락은 중복을 제거하고, 각 학습 선박의 양성과 배경 가중치 총합을 각각1로 맞춘다. 각 맥락에서 양성1개와 카탈로그 균등 배경16개를 만들고, 관측 크기 유지/결측 두 조건에 가중치를 나눈다. 음성 추출에서 정답과 우연히 겹친2/3개도 균등 배경 분포의 일부로 보존했다.

| 학습 자료 | fold1 | fold4 |
|---|---:|---:|
| 학습 선박 | 4,680 | 4,681 |
| 고유 제원 맥락 | 7,343 | 7,341 |
| 양성·배경 학습 쌍 | 249,662 | 249,594 |
| 학습/검증 정답 선박 중복 | 0 | 0 |

추론 객체에는 범주/구간별 코드와 지원 척수만 저장하며 선박별 제원표·이름표·호출부호표는 없다. ID는 오프라인 정답 연결·선박 분리에만 사용한다. 공식 데이터와 행 독립 범위는 [대회 규칙](https://dacon.io/competitions/official/236771/overview/rules)을 다시 확인했다. 사용자 방침인 호출부호·동일 선박 조회 제외도 유지했다.

## 고정한 비교

분류기 학습과 새 외부 정확도를 보기 전에 [프로토콜](../experiments/context_density_v1_protocol.json)을 저장했다. 그 전에 수행한 것은 학습 전용 지원 통계·자료 가중치·입력 불변성 검사다.

LightGBM binary200회, 깊이4·잎15·학습률0.05·L2=10·최소 Hessian10을 고정했다. 각 fold에 조건부 모델, 후보 속성만 쓰는 주변 모델, 질의 맥락을 서로 다른 학습 선박 사이에서 섞은 대조군을 학습했다. 총6개 모델이다. 대조군도 같은 자료·가중치·학습기를 사용하며 후보로 채택하지 않는다.

새 선택 점수는 `log(v12 확률) + 0.5 × clip(조건부 로짓 − 주변 로짓, −log4, log4)`다. 후보 하나의 배율은0.5~2로 제한한다. 대조군에는 조건부 로짓 대신 섞은 맥락 모델의 로짓을 넣는다. 실제 v12의 원래 상위20과 기존 신경망 생략 행의 기본 분포를 재현했으며, 제원 보정에는 예전 신경망 생략 경계를 적용하지 않는다. 한글 행만 바꾸고 외부 정답을 후보에 주입하지 않는다.

초기 조건은 v12 대비+0.003, 최악 fold−0.002 이상, hard/단어 생략 한글−0.002 이상, clean 정답 손실1행 이하, 섞은 맥락 대조군 대비+0.001이다. 실패 후 계수·깊이·구간을 다시 탐색하지 않는다.

## 실패 후의 범위 진단

결과를 본 뒤 기존 오답을 분류하는 별도 진단을 수행했다. **후속 후보나 실제 성능이 아니라, 현재 메커니즘의 제약을 설명하는 정답 사용 진단이다.**

같은 두 fold의 testlike에서 실제 한글이 남은 v12 오답324행을 분류했다.

| 원인 | 행 수 |
|---|---:|
| 정답이 고정 상위20 밖 | 51 |
| v12 승자와 정답의 인코딩된 제원 특징이 완전히 같음 | 142 |
| 같은 제원인 다른 후보가 정답보다 높은 기본 확률을 가짐 | 40 |
| 고정한 보정 배율로는 역전할 수 없음 | 24 |
| 정답을 아는 이상적인 제원 보정이라면 회복 가능 | 67 |

정답과 같은 제원 집단에는 최대 배율2, 다른 집단에는 최소 배율0.5를 주고 원래 정답은 전부 보존하는 낙관적 가상 선택도 testlike **0.926812**였다. **이는 현재 상위20·구간화·보정 폭에 한정한 진단이며 대회 점수의 상한이나 다른 모델의 상한은 아니다.** 다만 이 설정의 학습량이나 트리 크기만 늘려0.97에 도달한다는 경로는 성립하지 않는다. [분류·사례](../experiments/context_density_v1_limits.json)

다음 실험은 같은 제원 집단 안에서 실제로 구분할 수 있는 이름 근거를 추가하거나 후보 누락을 해결해야 한다. 그 방법이 v12를 넘는다는 근거는 아직 확보하지 못했다. 제원이 완전히 같은 후보에 강한 확신을 더하는 보정은 새 정보를 만들지 않는다.

## 보존과 현재 상태

# ByT5로 관측 이름 구간을 학습하는 별도 이름 전문가

2026-10-29. 현재 상태: **두 fold의 학습·재학습과 두 점수 방식 평가 완료, 모두 기각**. 원래 확률 방식은0.904412, 길이 정규화는0.898605로 같은 fold의v12 0.908779보다 낮았다. 추가한[기존 Kanana 전방 확률 진단](forward_name_probe_20261029.md)도 통과하지 못했다. 새 최종 모델·ZIP·실제 제출 없이v12를 유지한다. 실제 최고는Public0.9065951735·591초·제출9회이며 목표0.97은 미달이다. ## 바꾸는 부분

직전[모호한 음성 손실 실험](ambiguity_loss_20261029.md)은 두fold에서v12보다 낮아 기각했다. 이번에는 문자 단위 범용 사전학습 모델인ByT5를 이름 전용 모델로 미세조정한다. 범용Kanana의 고정 역방향 점수,37×37 문자 비용, 기존BGE 손실 조정과 다른 모델·학습 목표다.

입력은`latin: 관측 한글명`, 출력은 관측에 대응하는 **영문 이름 구간**이다. 약칭을 주고 사라진 전체 이름을 복원하도록 강제하지 않는다. GT·IGT·국적·선종·입항연도·ID·호출부호는 이 이름 모델에 넣지 않는다.

실제 공식 한글 기록과기존seed7의4개 증강에서 정답 카탈로그 영문명의 연속 단어 구간을 만든다. 기존 질의별Kanana 빔과 **정규화 문자열이 정확히 같고, 서로 다른 영문 구간이 하나뿐이며, 숫자 묶음이 보존되는 경우**만 감독 신호로 채택한다. 외부 선박 사실이나새LLM 합성 음역은 생성하지 않는다. 기존 공식 기록의 인공 철자/생략 증강은 포함한다.

이 정렬도 약한 레이블이다. 빔이 관측하지 않은 단어를 잘못 보완했을 가능성까지 배제하는 발음 정답 검증은 아니다. 동일한 한글 입력에 여러 영문 표기가 남으면 질의별로 균등 가중하며 선박 ID를 외우는 분류 목표로 바꾸지 않는다.

ByT5-small의299,637,760개 파라미터 전체를 학습한다. FP32 파라미터·BF16 forward·eager attention·gradient checkpointing, batch16, Adafactor 기본학습률1e-3·weight_decay0.01·global norm1·seed42를 고정했다.12epoch 계획의10% warmup 후 선형감쇠한다.

내부검증의 토큰NLL을epoch1·3·6·12에서만 확인해 최저NLL epoch를 고른다. 그다음 원래 공개 체크포인트에서 다시 시작해 외부 학습 전체 이름 쌍으로 해당epoch만큼 재학습한다. 재학습의 LR 계획도12epoch 기준으로 유지한다. 외부fold 점수로 epoch나 혼합 계수를 고르지 않는다. 내부NLL 감소는 대회 정확도 향상과 구분한다.

실제 선택은fold1에서3epoch, fold4에서1epoch였다. fold1의 내부검증NLL은1/3/6/12epoch에서2.3544/2.0080/2.2520/2.9696, fold4는1.8105/1.8439/2.1509/2.1682였다. 학습 손실이 계속 감소해도 미학습 선박의 내부 검증은 악화해 이후epoch를 선택하지 않았다. 선택한 학습량으로 각각877/852쌍을 다시 학습했다.

두 pilot와 두 재학습을 합쳐1,215업데이트에서 손실·기울기가 모두 유한했다. 경로의`full`은 해당 외부fold 학습 집합 전체라는 뜻이며, 제출용으로 모든 공식train을 학습했다는 뜻은 아니다.

## 새 점수와 기존v12 결합

영문 구간이 관측 한글명에서 나올 확률`P(영문 구간+EOS | 관측 한글명)`을 강제 디코딩으로 계산한다. 후보 전체 이름의 사전확률은0.5, 다른 서로 다른 연속 구간의 합은0.5로 고정해 이름별 확률을 가중합한다. 단어 하나인 이름은 사전확률1이다. 무제한 최대값을 골라 긴 이름이 유리해지지 않게 한다.

공개 미학습ByT5로 같은 점수·혼합을 계산하는 대조군을 둔다. 이 모델 카드는 미세조정이 필요하다고 명시하므로 미학습 모델을 실전 추천 모델로 취급하지 않는다. 새 전사 학습의 추가 효과를 확인하는 대조군이다.

후보는 **실제v12의 상위20 분포70% + 이름 전문가30%** 하나다. 기존v12가 신경망 계산을 생략한 행에서는 실제로 반환하는 기본 점수를 사용하며 생략된 Qwen/BGE 점수를 임의 복원하지 않는다. 상위20 안에서 정규화하고 기존v12 승자가 모두 재현되는지 확인했다. 평가 정답을 후보에 추가하지 않는다.

이름 모델 계산은 앵커 상위2개 확률 차이가`3/7+1e-6`보다 클 때만 생략한다. 새30% 기여로는 그 승자를 뒤집을 수 없다는 경계다. 예전25% 구조의1/3 경계를 그대로 쓰지 않는다. [자료/경계 검사](../experiments/byte_names_v1_setup_checks.json)

새 구성의 결정 폭은 학습 전에 정답을 아는 가상 전문가로만 점검했다.30%에서 로컬 오라클은약0.979355이며 실제 성능이나 Public 상한이 아니다. 이 진단을 이용해 모델이 강해져도 구조가 역전을 막는 경우를 점검했으며, 학습 결과를 본 뒤 혼합 계수를 탐색하지 않는다. [정답 사용 구조 진단](../experiments/byt5_residual_oracle_20261029.json)

## 수치 재현성과 출처

고정된 공개`google/byt5-small` revision `68377bdc18a2ffec8a0533fef03b1c513a4dd49d`를 내려받았다. Apache-2.0, 원본PyTorch 파일1,198,627,927바이트다. 기존v12 가중치는 바꾸지 않는다.

추론은FP32·TF32 비활성·eager attention·고정batch16을 사용한다. 각 쌍 자체의 길이로 정한최소encoder128/decoder96의 길이 구간으로 패딩하며 마지막batch도16으로 채운다. 잘라내기는 없다. 역순·단독/동반쌍 변경에서 점수가 완전히 같았고, 수동교차엔트로피와의 차이는0이었다. 이는 수치 검사이며 과제 성능 검사가 아니다. [사전 수치 검사](../experiments/byte_names_v1_preflight.json)

오프라인 쌍 캐시는 실제 저장 모델에서도 같은 검사를 다시 통과한 뒤 쓰며 가중치 해시를 붙인다. 실전 추론은 각 질의의 후보 집합만으로 계산하고 다른 행에서 채운 쌍 캐시에 의존하지 않는다. 학습 체크포인트는 두 슬롯에 번갈아 저장하며 모델·옵티마이저·난수 상태가 다 저장된 뒤 완료표식을 쓴다.

## 학습 길이에 따른 정규화 보조안

영문 구간마다 길이가 다른 점을 검토해 공통 학습·일부 원래 확률 계산이 진행된 뒤, **외부 정확도 결과를 확인하기 전에** 조건부 보조안 하나를 별도 등록했다. 원래 모델·학습·30%혼합·채택 조건은 바꾸지 않았다. 원래 방식이 초기 조건에 미달할 때만 실행하며, 원래 방식이 초기 통과 후 별도 진단에서 실패한 경우에는 이 보조안을 탐색하지 않는다. [추가 프로토콜](../experiments/byte_names_length_v1_protocol.json)

각 구간의로그확률을그 구간의UTF8 바이트+EOS 길이로 나누고, 해당외부학습의 정답구간 중앙길이를곱한 뒤 같은구간 가중합을사용한다. 두fold의중앙길이는모두12였다. 이 값은검증점수로맞춘계수가아니라학습자료에서정한상수다. 이것은길이를보정한호환성점수이며정규화전의엄밀한문장확률과구분한다. 미학습대조군에도동일하게적용한다.

모든1,729개 학습쌍에서 계산한바이트길이가실제ByT5 토크나이저의대상길이와 같았고, 구간별문자평균우도가같을때이름길이/구간수에따른점수가중립적인지확인했다. 보조안은이미학습한모델과쌍점수를재사용했으며추가모델학습은하지않았다.

## 채택 조건과 현재 범위

[사전 프로토콜](../experiments/byte_names_v1_protocol.json)은 새 학습과 새 모델의 외부 예측 전에 저장했다. fold1·4에서v12 대비testlike+0.003, 최악fold-0.002 이상, hard/단어생략 한글-0.002 이상, clean 정답 손실1행 이하, 미학습ByT5 대조군 대비+0.001을 모두 요구한다.

통과 시별도fold3의 고정7종 변형을 학습 전용 검색/매퍼·few-shot 선박 제외로 평가한다. 평균 하락 한도는-0.002다. 이후 전체5-fold에서+0.005·4개fold 개선·hard한글-0.001/단어생략-0.002/OOF-0.0006 이상·대조군 대비+0.001을 요구한다. 그 다음에만 최종 전체 학습과새패키지·실제행독립/시간 검사를 한다. 이 선박·CV는 과거 실험에 등장해 완전 미관찰 검증이 아니다.

초기조건미달로별도fold3 후보진단·나머지fold·전체5-fold·제출용최종전체학습·새ZIP은진행하지않았다. 호출부호·동일선박조회·외부선박자료·test분포는사용하지않았다. 실패후계수·정렬기준을재탐색하거나조건부사전확률모델을자동학습하지않았다.

독립후속진단으로기존범용Kanana의전방조건부확률을다른fold의48척에서고정설정으로측정했으나17→15척으로하락해확대하지않았다. 이진단은ByT5혼합계수수정이나새선박자료추가가아니며[별도기록](forward_name_probe_20261029.md)에남겼다.

# v12 후속: 약칭·톤수 결측 학습 구성 변경

기준일 2026-10-28. 사용자가 [추천한 방향](performance_rethink_20261028.md)의 실제 개선 작업을 승인했다. 현재 Public 최고는 v12 **0.9065951735**, 서버 **9분 51초**다. 호출부호·train/test 동일 선박 조회 제외를 유지하고 기존 모델·ZIP·실제 제출 기록을 보존한다.

## 실행한 가설과 고정 조건

**A1 — 깨끗한 약칭+결측 노출:** v12의 원래 2,400개 학습 그룹을 재현하고, 그중 목표 유형이 아닌 일부만 새로운 실제 단어 생략+GT·IGT 결측 사례로 바꾼다. 최종 목표 유형은 **480개(20%)**다. 새 사례는 기존 선택 그룹과 동일 모델 입력·정답 쌍이 겹치지 않도록 중복을 제거한다. 기존 목표 유형은 유지한다.

새 질의는 학습 fold의 실제 한글 기록에서 단어 하나를 제거해 생성한다. 다른 이름 철자 변형을 넣지 않고 원래 선종·국적은 유지한다. 신경망이 실제 적용되는 한글 입력만 새 A1 사례로 쓴다. 후보 검색·범주 매퍼·LightGBM 음성 선별은 외부 검증 선박을 제외한 학습 fold로만 준비한다. A1에서는 기존과 같이 정답이 검색된 사례만 사용한다.

**A2 — 학습 양성 검색 실패 복원:** A1이 기준을 통과하지 못하면 별도 안으로 비교한다. 원래 후보에 정답이 없어 제외됐던 고유 학습 사례를 최대 240개까지 복원하며, 총 그룹 수는 2,400개를 유지한다. 정답 카탈로그 행은 학습에만 붙이고 원래 검색된 혼동 후보 7개를 음성으로 쓴다. 검증·추론에는 정답을 넣지 않는다. A1과 처음부터 섞지 않는다.

두 안 모두 BGE 모델·입력 형식·LoRA rank8/alpha16/dropout0.05·학습률 1e-4·2개 그룹/배치·1 epoch·시드42·최대256토큰을 유지한다. 결합도 **v8 75% + 기존 Qwen 12.5% + 새 BGE 12.5%**다. 데이터 준비에 LLM이 쓰이면 학습 직전에 시드를 다시 설정한다. 병합→BF16 저장→재로딩 후 평가한다.

## 사전 검증 조건

학습 전 [A1 프로토콜](../experiments/encoder_focused_protocol.json)과 [A2 프로토콜](../experiments/encoder_restore_protocol.json)에 기록했다. 최초 prepare-only는 사례 수·토큰·분리 여부만 확인했으며 새 모델 점수는 계산하지 않았다.

1. fold 0·2: testlike 순증 **+0.002 이상**, 각 fold -0.002 이상, hard 한글·톤수 있는 약칭 하락 최대 0.002, 원본 정답 손실 최대 1행.
2. 통과하면 fold 4 모델을 학습해 새 1,827행 진단에 적용한다. 후보 검색·범주 매퍼도 학습 선박으로 분리하고 few-shot 선박을 제외한다. 평균 정확도 하락 한도 -0.002다.
3. 전체 5-fold: testlike **+0.003 이상**, **4/5 이상 fold 개선**, hard 한글 하락 최대 0.001, 단어 생략 한글 하락 최대 0.002, OOF 하락 최대 0.0006.
4. 모든 조건을 통과한 후보만 전체 데이터 학습·독립 실행·행 독립성·ZIP 검사를 진행한다. 실제 대회 제출 기능은 없다.

## 구현과 준비 확인

- `src/focused_encoder_experiment.py`: v12 그룹/양성 토큰 재현, 고유 질의 생성, 학습 fold 전용 새 후보·음성 생성, 고정 예산 교체, 모델 학습·저장·재로딩 평가.
- `tools/audit_encoder_extension.py`: 같은 후보·같은 기본 점수에서 v12와 비교한다. 반복 사용한 검증이며 기존 v8 평가 후보 검색 매퍼 예외는 남는다.
- `tools/run_focused_iteration.py`: 초기 조건→별도 진단→전체 CV를 순서대로 진행하고 A1 탈락 시 A2를 별도로 비교한다.
- `tools/train_focused_final.py`, `tools/release_focused_encoder.py`: 조건 통과 시에만 `ranker_v13_data` / `submit/v13_data` / `dist/v13_data.zip`을 만든다. 기존 파일과 경로를 분리했다.

첫 fold 0에서 원래 목표 유형은 **92개**, 새 고유 후보 풀은 526개였으며 그중 양성 검색·후보 수 조건을 통과한 것은 504개다. **388개를 교체해 480개**로 맞췄다. 바꾸지 않은 그룹은 원래 토큰과 완전히 같고, 원래 선택 2,400개 모두의 양성 토큰도 재현했다. 학습/검증 선박 중복 **0척**, 256토큰 잘림 **0개**다.

## 초기 두 fold: 확대 기준 통과

| fold 0·2 합산 | v12 | A1 |
|---|---:|---:|
| testlike | 0.917877 | **0.921622** |
| hard | 0.866003 | 0.866003 |
| OOF | 0.997532 | 0.997532 |
| 단어 생략 한글 | 0.846501 | **0.862302** |
| 생략+결측 한글 | 0.586907 | **0.595937** |

testlike 순증 **+0.003745**, fold별 +0.004687 / +0.002700이다. 변형은 **18행 회복·7행 손실**, hard는 5행 회복·5행 손실, 원본 변화는 0행이다. 선박 bootstrap 95% 구간 **[-0.001187, +0.008909]**로 0을 포함한다. 이는 두 fold 결과이며 전체 5-fold·Public 값이 아니다. [초기 결과](../experiments/encoder_focused20_v1_screen_snapshot.json)

병렬로 만든 학습 그룹 중 3개를 직렬 검색·음성 선별·인코딩으로 재계산해 정확히 같음을 확인했다. 학습 ID·호출부호·정답 ID 값을 바꿔도 모델 입력 토큰이 같았다. [검사](../experiments/run_check_focused_groups.log)

최종 전체 데이터용 그룹도 별도 `full` 캐시로 준비했다. 기존 목표 유형 91개를 **480개**로 맞추기 위해 새 고유 사례 389개로 교체했고, 학습 토큰 잘림은 0개다. 이는 데이터 준비이며 최종 신경망 학습은 아직 하지 않았다. CV에는 이 `full` 캐시를 사용하지 않는다.

## 별도 진단과 A2: 두 안 모두 기각

A1의 fold 4 별도 진단 1,827행에서는 v12 **0.790914 → 0.787083**, 차이 **-0.003831**로 사전 하락 한도 -0.002를 넘었다. 6행 회복·13행 손실이었고, 선박 bootstrap 95% 구간은 [-0.011859, +0.003664]다. 초기 검증 개선만으로 채택하지 않았다. [별도 진단](../experiments/fresh_extension_f4_encoder_focused20_v1.json)

A2는 fold 0·2 testlike **0.917877 → 0.919031**(+0.001153), hard **0.866003 → 0.866793**, OOF 유지였다. 두 fold 모두 소폭 개선했지만 사전 최소 순증 +0.002를 충족하지 못했다. [A2 결과](../experiments/encoder_restore_v1_audit.json)

[선택 기록](../experiments/focused_selection.json)의 selected는 null이다. 나머지 fold·최종 신경망·새 ZIP은 만들지 않았으며 새 Public·서버 시간도 없다. 기존 v12를 유지한다. 후속으로 공식 카탈로그의 새 이름을 이용한 음역 사전 적응을 별도 실험한다. fold 4 진단은 이제 관찰한 검증으로 기록한다.
